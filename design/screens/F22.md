# F22 Photo check (crop doctor)

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-004 (blurry photo rejected with retake tip; up to 3 photos), NF-004 (image budget), DX-001 (on-device quality), NF-010 (low literacy: icons + short words, audio later). Derived from SPEC 13.3 "F22 Photo check (blur warning with retake)".

Implementation: screen shell lands with FM-004 (M6). Pipeline and card exist now: `apps/mobile/packages/core/lib/src/photo/` and `lib/src/widgets/photo_review_card.dart`.

## Purpose

The farmer took a photo on F21 (camera with `CameraGuideOverlay`). Before anything is uploaded, tell them in one glance whether it is usable, and if not, what to do (steady hand or better light) with a single big Retake button. Same pipeline as the agent app, so the corpus receives identical 1280 px / q80 images (DX-002 embeddings are consistent).

## Flow

1. F21 returns raw bytes + capture time. Farmers are never location-tracked; no GPS is passed unless the farmer explicitly chose the farm on F03/F04 (then the farm point, not the device fix).
2. `PhotoProcessor.process(bytes, captureTime:)` in the background; `PhotoQualityCheck.evaluate(processed.bytes)`.
3. Card: good → "Use photo" enabled; blurry / dark → Use disabled, tip line, Retake goes back to F21 with the matching overlay tip lit (`CameraGuideOverlay(tipKey:)`).
4. Up to 3 photos; "Continue" → F23 (crop pick if not detected) → F24 Analysing. Offline: queued, F24 shows "we'll check when you're online".

## States covered

| State | Behaviour |
|---|---|
| Checking | Info badge; Use disabled |
| Good | Success badge; Use enabled |
| Blurry | Danger badge; `photoTipBlurry`; Use disabled (FM-004 acceptance) |
| Too dark | Warning badge; `photoTipDark`; Use disabled |
| 3 photos accepted | "Add another" hidden |
| Offline | Same; upload queued |
| Sunlight | Black text, 2 dp borders, no tinted containers |

## Accessibility

Tip line is body size (16 sp) and paired with an icon in the badge; Retake and Use are 48 dp with icon + word; card semantics announce title, verdict and size. Audio playback of the tip lands with the farmer audio assets (NF-010).
