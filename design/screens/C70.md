# C70 Validation inbox

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. SideNav "Flags" (`nav.flags`), shown to owner, director, auditor, cluster head, store manager, tenant admin and field officer (own flags only).
Requirements: WC-010 (acceptance "each flag has an owner and an SLA"), VA-002, VA-003.

Implementation: `apps/console/components/flags/FlagInbox.tsx` (route `app/(console)/flags/page.tsx`), `SlaTimer.tsx`, `FlagStatusBadge.tsx`; DS `FlagCard` (optional `ownerName`, `sla`, `badges`). Data: `lib/hooks/flags.ts` `useFlagInbox` (infinite query) over `GET /v1/flags?status=&severity=&rule_id=&subject_type=&owner=me&overdue=&cursor=`; owner names from `GET /v1/users` (`useUserNames`, roles that can list users; others see the role).

## Layout

1. Page header `flags.title` / `flags.subtitle`.
2. Filter panel (`flag-filters`): Status (Unresolved = open + in review + escalated, default; All; each status), Severity, Rule (rules in `rules/*.yaml` + any in the counts), Subject (farmer, employee, visit, store), "Assigned to me" (`owner=me`: owned or watched), "Overdue only"; Clear when filtered.
3. Counts row (`flag-counts`): total and one badge per severity from `counts.by_severity` (whole filtered set, not just the loaded page).
4. Groups: one section per severity (high, medium, low; heading `flags.groupSeverity` "High · 4" with the server count), inside it one block per rule (`flags.groupRule` "VA-F06 · 2", loaded cards), cards in a 2-column grid.
5. "Load more flags" while `next_cursor` is set.

## FlagCard content

Severity badge + status badge, rule id + version (`VA-F06 v1`), title, subject line, owner (`flags.ownerNamed` "Mahesh Goud (Cluster head)", `flags.ownerYou`, or the role), raised time (DD-MM-YYYY HH:mm IST), live SLA countdown and "Open flag" -> C71.

SLA timer (`SlaTimer`, ticks every second): "Due in 2d 03h" / "3h 05m" / "4m 09s"; warning colour when less than 20% of a day is left; overdue "Overdue by 1h 30m" in the danger colour (`data-overdue="true"`, also trusts the API's `overdue`); resolved flags show "SLA closed".

## States

Session loading skeleton; signed out -> sign-in prompt; role without access -> ForbiddenState (`admin.forbiddenTitle`); loading -> 4 FlagCard skeletons; empty -> `flags.emptyTitle` / `flags.empty`, filtered empty -> `flags.emptyFilteredTitle`; error -> ErrorState with retry (403 -> ForbiddenState).
