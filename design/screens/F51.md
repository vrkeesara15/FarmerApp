# F51 Payment success receipt

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-010 (P0). Derived from SPEC 13.3 (F51), 13.1 components and SPEC 2.4 / 7.

Implementation: `apps/mobile/apps/farmer/lib/screens/payment_receipt_screen.dart` (route `/khata/receipt`, receipt in `extra`).

## Purpose

Confirms the payment: amount, time, reference and the khata balance fetched right after.

## Components used

| Component | Notes |
|---|---|
| Success mark | Green check 96 dp |
| Amount | Display size |
| Card | Paid on, reference, balance now |
| AppButton | "Done" → F10 |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Amount / time / reference | The paid UPI payment | ₹12,500.00 · pay-1 |
| Balance now | Khata fetched after paid | ₹0.00 |

## Actions and navigation

| Action | Result |
|---|---|
| Done | F10 |

## States covered

| State | Behaviour |
|---|---|
| Opened without a receipt | Only the success heading and Done |

## Accessibility and literacy

Every icon is paired with a text label; targets are at least 48 dp; body text 16 sp or larger; the key instruction has an `AudioButton` next to it (NF-009: device TTS in the chosen language behind the `AudioPrompt` seam, "Audio unavailable" when the phone has no voice for it). No text input (NF-010). At most two decisions on the screen.
