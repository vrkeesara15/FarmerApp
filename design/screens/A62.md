# A62 My flags

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. From Me and from a flag notification. Route `/me/flags`.
Requirements: VA-005 (the employee sees flags about themselves once resolved, with the outcome, and can add an explanation while open), VA-002 (evidence), FA-005 (voice on the explanation).

Implementation: `apps/mobile/apps/agent/lib/screens/field/my_flags_screen.dart` (`MyFlagsScreen`) over `myFlagsProvider` (`FieldRepository.watchFlags`, the `kv` cache). `refreshFlags` pulls `GET /v1/flags/mine?state=open` and `?state=resolved`. **There is no other source of flags in the app**, so no other officer's flag can appear.

## Layout (top to bottom)

1. AppBar `flagsTitle`; OfflineBannerLive.
2. `fieldAsOf(time)` caption.
3. `flagsOpenSection` then `flagsResolvedSection`, each a list of cards (key `flag-<id>`):
   * severity icon and label (`flagSeverityLow|Medium|High`), the rule title, then `flagState*` and the date;
   * the officer's own explanations, quoted (key `flag-explanation-<id>`);
   * **open**: `flagOutcomeHidden` (key `flag-outcome-hidden-<id>`) — the outcome is not on the wire yet — plus a `VoiceTextField` (`flag-explain-field-<id>`, mic `flag-explain-mic-<id>`) and `flagAddExplanation` (key `flag-explain-send-<id>`);
   * **resolved**: the outcome block (key `flag-outcome-<id>`) with `flagOutcomeTitle`, the label and the reviewer's note, and no explanation field (the server answers 409 `flag_resolved`).

## States

| State | Behaviour |
|---|---|
| Loading | Spinner |
| No flags | EmptyState `flagsEmpty` / `flagsEmptyHelp` (key `flags-empty`) |
| Open | Outcome hidden, explanation field shown |
| Resolved | Outcome shown, no explanation field |
| Sending | Button in its loading state |
| Offline | `flagExplanationNeedsNetwork` (key `flag-explain-offline`); nothing is queued blind |
| Sunlight | Black text, 2 dp borders |

## Data

| Field | Source |
|---|---|
| Flags, state, severity, explanations, outcome | `GET /v1/flags/mine` (cached in `kv` under `field.flags`) |
| Evidence metrics | `evidence.metrics` of the detail — numbers only, no other officer's records |
| Explanation | `POST /v1/flags/mine/{id}/explanations` (online only) |

## Copy keys
