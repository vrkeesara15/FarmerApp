# C30 Farmers directory

Surface: Web console, Light and Dark. SideNav "Farmers" (`nav.farmers`).
Requirements: WC-003, AN-004 (list), AN-011, AN-014 (masked phone in lists). Roles: owner, director, tenant admin, auditor, cluster head, store manager (own store), field officer (own farmers).

Implementation: `apps/console/app/(console)/farmers/FarmersView.tsx`. Data: `useFarmerDirectory` (TanStack `useInfiniteQuery`) over `GET /v1/analytics/farmers`.

## Layout

1. Header `farmers.title`, range, scope note, total (`farmers.total`, "72 farmers").
2. FilterBar (cluster, store, officer, crop, date; export = CSV of the loaded rows, masked phones only).
3. Directory filters (`farmer-filters`), all in the URL: search (`q`: name, last 4 phone digits, village; debounced 350 ms, URL replaced), district (from the stores in view), crop stage (`stage.*`), credit risk (low / medium / high), last visit (7 / 30 / 90 days, over 90 days, never); Clear.
4. Definitions row (credit overdue, LTV, active farmer).
5. DataTable, server-side sort (`sort` in the URL, `-` = descending) on farmer, last visit, last purchase, balance, overdue, LTV:
