# C31 Farmer 360

Surface: Web console, Light and Dark. Route `/farmers/{id}` (+ filters, `tab`).
Requirements: WC-003 acceptance "Profile reflects latest sync" (the API reads the live tables), AN-004, AN-014 (full phone only here; the API audits detail views). Roles as C30; out of scope → 404.

Implementation: `apps/console/app/(console)/farmers/[id]/Farmer360View.tsx`; farms map `components/analytics/maps/FarmsMap.tsx`. Data: `useFarmer360` over `GET /v1/analytics/farmers/{id}/360`.

## Layout

1. Back link "Farmers"; header: name; village · district · store; full phone; consent badges — data consent given / withdrawn (success / danger), marketing allowed / no marketing; Active / Inactive. Export = CSV of the open tab.
2. "Registered by {officer} on DD-MM-YYYY · Updated DD-MM-YYYY HH:mm".
3. Summary StatTiles: lifetime value (InfoTip: SPEC 5.2 Farmer LTV), khata balance, overdue, last visit, last purchase, app sessions (60 days).
4. Tabs (`tab` in the URL):
   - Farms and crops: map with every farm boundary polygon (`.farm-polygon`, tooltip name · acres) + crops table (farm, crop, variety, stage badge, sown, expected harvest, acres, soil · irrigation).
   - Visits: when, officer (→ C21), purpose, crop stage, VisitScoreBadge, confirmed, photos (column appears when the payload carries photo counts); "Diagnoses with photos" section — EmptyState until the diagnosis engine (M6).
   - Orders: placed, invoice, store, channel (`orderChannel.*`), status (`orderStatus.*`), lines, total.
   - Khata: balance, overdue, next due date, last payment, credit risk badge, credit limit per store, overdue-by-age bars (0–30 … 90+), note that entry-level lines live on the store khata screen.
   - Consent: history table (when, purpose, given / withdrawn badge, policy version, channel).
   - App usage: has an app login, last session, sessions in 60 days, LTV; note on the refresh-token proxy.

## States

Loading skeletons; 404 → `not-found-state`; 403 → `forbidden-state`; per-tab EmptyStates (`farmer360.farms.emptyTitle`, `visits.emptyTitle`, `orders.emptyTitle`, `diagnoses.emptyTitle`).

## Copy keys

`farmer360.*`, `farmers.risk.*`, `orderChannel.*`, `orderStatus.*`, `buckets.*`, `stage.*`, `purpose.*`, `visitStatus.*`.

## Tests

`e2e/analytics.spec.ts` "C30 search -> C31 farmer 360 tabs" (header, consent, farms map, every tab, `tab` survives reload).
