# A42 Analysing (scouting)

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FA-019, FA-025 / NF-003 (offline outbox, resumable uploads). Derived from SPEC 13.2 "A42 Analysing (queued offline state too)".

Implementation: waiting state of `ScoutResultScreen` (`/scouting/<diagnosisId>`).

## Behaviour

- A41 "Check my crop" saves the photos (`DocumentsPhotoStore`), queues one resumable upload per photo (`purpose: diagnosis`) and one `diagnosis` create op `{farmer_id, crop_plot_id, crop_id | unknown, images: [{blob_uri, sha256, quality}], crop_guess?, on_device_model, crop_stage, captured_at, ask_expert}` that waits for the uploads; then syncs when online.
- Online: spinner + "Checking your crop…"; `DiagnosisPoller` (2 s → 10 s) and the sync feed deliver the answer; the screen turns into A43.
- Offline (`scout-queued`): "Queued. It will be sent when the phone is online." with the farmer / plot line; the background sync (WorkManager, reconnect) sends it later.
