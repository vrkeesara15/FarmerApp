# S09 Credit approvals / limits

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store/credit`. Requirements: ST-007 (UI).

Implementation: `apps/mobile/apps/agent/lib/screens/store/credit_screen.dart`.

## Layout

Cluster head: pending requests (`GET /v1/credit-approvals?status=pending`), one card per request (`approval-<id>`): farmer, store chip, `storeApprovalAmount`, `storeCreditBalance`, `storeCreditLimit`, `storeShortfall`, requested time; `storeReject` / `storeApprove` (`approval-reject|approve-<id>`) open a note dialog (`approval-note`, `approval-confirm`) -> `POST /v1/credit-approvals/{id}/approve|reject`; `approval_not_pending` -> `storeApprovalGone`. Empty: `storeApprovalsEmpty` (`credit-empty`).
Store manager (two panes at >= 700 dp): `storeSetLimitTitle` form (`credit-limit-form`): farmer phone (`credit-phone`, `credit-find`; local farmer, else `storeLimitFarmerNotFound`), limit in rupees (`credit-amount`, helper `storeManagerCapHint(₹50,000)`; above the cap the warning `credit-over-cap`), `storeSetLimit` (`credit-save`) -> `PUT /v1/farmers/{id}/credit-limit`; 403 `credit_limit_needs_cluster_head` -> `storeLimitNeedsClusterHead`; success `storeLimitSaved`. The pending list is shown read-only beside it.
