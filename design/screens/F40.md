# F40 My crops and farms

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-003, FM-007 with NF-002, NF-009, NF-010. Derived from SPEC 13.3 (F40), 13.1 components and SPEC 2.4.

Implementation: `apps/mobile/apps/farmer/lib/screens/my_crops_screen.dart` (route `/crops`), `widgets/farm_edit.dart` (`FarmSummaryCard`).

## Purpose

Every farm the farmer has, with its map thumbnail, water and soil, and each crop with its stage and **next task** from the synced crop calendar. "Add a crop" opens F41; a crop row opens F42; chips lead to the weather (F43) and the district alerts (F44).

## Components used

| Component | Notes |
|---|---|
| AppBar | `kisanMyCrops` |
| OfflineBanner | While the phone has no network |
| SpokenText | `kisanWelcomeEditHelp` with an `AudioButton` (NF-009) |
| FarmSummaryCard | Map thumbnail or landscape tile, `kisanAcres`, water and soil chips (tap opens a tile sheet), one row per crop plot |
| Next task | `calendarNextTask(title)` from the calendar, `calendarAllDone` when nothing is left, `kisanNextTaskSoon` until the calendar has been pulled |
| Crop calendar button | `kisanCropCalendar` -> F42 (`plot-calendar-<plotId>`) |
| ActionChips | `kisanWeather` -> F43, `kisanAlerts` -> F44 |
| FAB | `kisanAddCrop` -> F41 (`crops-add`) |
| AsOfLabel | "Updated 19-09-2026 10:00" / "Offline. Saved on ..." |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Farms, crops, stage | Cached profile (`kisan.cache.profile`) | Home farm, Cotton, Flowering |
| Next task | Cached calendar (`kisan.cache.calendar`) | Next: Check for sucking pests |
| Water, soil | Cached profile | Borewell, Black |

## Actions and navigation

| Action | Result |
|---|---|
| Open / pull down | Refreshes the profile and the crop calendar |
| Water / soil / stage chip | Tile sheet, saved online, queued offline |
| Crop calendar | F42 for that plot |
| Add a crop | F41 |
| Weather / Pest alerts | F43 / F44 |

## States covered

| State | Behaviour |
|---|---|
| Loaded | Farms with crops and next tasks |
| No calendar yet | "Next task: coming soon" |
| Offline | Banner, everything from the cache with "as of" |
| No farms | `kisanNoCropsYet` empty state |

## Accessibility and literacy

Icons always carry a label; targets are at least 48 dp; body text is 16 sp or larger; the help line has an `AudioButton`. Nothing on the screen asks the farmer to type (NF-010) — every edit is a tile.
