# F41 Add a crop

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-007 with NF-009, NF-010. Derived from SPEC 13.3 ("F41 Add crop (tiles + sowing date picker with calendar)").

Implementation: `apps/mobile/apps/farmer/lib/screens/advisory/add_crop_screen.dart` (route `/crops/add`).

## Purpose

Add a crop to a farm without typing: big crop tiles, a sowing-date calendar, and icon tiles for water and soil. Saving creates the crop plot and pulls the crop calendar again, so F42 has the new crop's tasks straight away.

## Components used

| Component | Notes |
|---|---|
| AppBar | `addCropTitle` |
| SpokenText | `addCropHelp` ("Tap the pictures. You do not need to type.") with audio |
| ChoiceGrid + ChoiceTile | `addCropWhichCrop` — the tenant's crop feed, the six pilot crops as the offline fallback (`add-crop-<code>`) |
| ChoiceGrid + ChoiceTile | `addCropWhichFarm` — only when the farmer has more than one farm |
| CalendarDatePicker | `addCropWhenSown` — an inline month calendar, never a text field; today back to one year (`add-crop-date`) |
| ChoiceGrid + ChoiceTile | `addCropWater` — the seven `IrrigationType` values with their pictograms |
| ChoiceGrid + ChoiceTile | `addCropSoil` — the seven `SoilType` values |
| AppButton | `addCropSave`, disabled until a crop and a date are chosen |

## Data written

| Field | Endpoint |
|---|---|
| Crop, sowing date, season | `POST /v1/farms/{id}/crop-plots` (`CropPlotCreate`; the season is derived from the date) |
| Water, soil | `PATCH /v1/farms/{id}` when the farmer changed them |
| Calendar | `GET /v1/me/calendar` right after, so the tasks are ready |

## States covered

| State | Behaviour |
|---|---|
| Nothing chosen | Save disabled |
| Saved | `addCropSaved` ("Crop added. Your calendar is ready.") and back to F40 |
| Offline | `kisanNeedsInternet`; the crop plot needs the server (the calendar is generated there) |
| No farm yet | `addCropNoFarm` empty state |

## Not built

The variety is optional in the API and is **not** asked here: there is no tap-only variety list yet and NF-010 forbids a text field. It is a follow-up once the crop feed carries varieties.

## Accessibility and literacy

Every tile is at least 96 dp high with a pictogram above its label; the calendar is the Material month grid (no keyboard entry mode); the help line is read aloud.
