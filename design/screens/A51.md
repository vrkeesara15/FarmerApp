# A51 Cart

Surface: Field agent app "Mitra", Light and Sunlight, 360x800.
Requirements: FA-020 (quantity, price, delivery or pickup).

Implementation: `screens/orders/cart_screen.dart` over `cartProvider` (`CartNotifier`, `packages/core/lib/src/orders/cart.dart`). Route `/orders/cart`.

## Layout

1. AppBar `cartTitle` + farmer.
2. Line cards (key `cart-line-<sku>`): name, own-brand badge, pack · unit estimate, line estimate, −/+ steppers (`cart-dec-<sku>` / `cart-inc-<sku>`, tooltips `cartDecrease` / `cartIncrease`; − at 1 removes).
3. After `insufficient_stock` (editing a rejected order): notice `cartShortTitle`, per line `cartShortLine(available, requested)` and `cartUseAvailable(n)` (key `cart-use-available-<sku>`); short lines block checkout.
4. `cartAddMore` (back to A50); `cartFulfilment` segmented Pickup / Delivery (`fulfilmentPickup` / `fulfilmentDelivery`).
5. Totals card: `cartSubtotal`, `cartTax`, `cartEstimatedTotal` (key `cart-total`) + `cartEstimateNote` — the same half-up per-line maths as the server (`CartTotals.of`), but the server prices the order.
6. CartBar `cartChoosePayment` → A52. Empty: `cart-empty`.

## Behaviour

Estimates only: money is server-owned (FA-025); the order payload carries sku + qty, never prices.

Every state has an offline banner (`OfflineBannerLive`); strings are ARB keys in all five languages; money via `formatInr`.
