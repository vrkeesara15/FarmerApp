# C50 Product master

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. SideNav "Products" (`nav.products`); sub-navigation to C51 / C52.
Requirements: WC-005 (SKUs, own-brand flag, barcodes, HSN / GST; CSV import / export groundwork for WC-013).

Implementation: `apps/console/app/(console)/products/ProductsView.tsx` (+ `_components/ProductDialogs.tsx`, `_components/ImportDialog.tsx`, `_components/fields.tsx`). Data: `lib/hooks/catalog.ts` (`useProducts`, `useCreateProduct`, `useUpdateProduct`, `useCreateSku`, `useUpdateSku`, `useImportCsv`) over `GET/POST/PATCH /v1/catalog/products`, `POST/PATCH /v1/catalog/skus`, `POST /v1/catalog/import/products`, `GET /v1/catalog/export?kind=products`. Validation: `lib/catalog-schemas.ts` (`productSchema`, `skuSchema`; react-hook-form + zod).

## Layout (top to bottom)

1. Page header `products.title` / `products.subtitle`; sub-navigation Products · Label claims · Price lists (`products.subnav`).
2. Filter bar (`data-testid="filter-bar"`): search (`common.search`, placeholder `products.searchPlaceholder`), category, brand type (`products.filters.*`), status (active / inactive / all); right side Export (`common.export`, roles owner, director, tenant admin, agronomist, auditor), Import CSV (`import.action`) and New product (`products.newProduct`) for owner / director / tenant admin only.
3. DataTable: one row per product with an expand toggle (`products.expandSkus` / `collapseSkus`) revealing one row per SKU.

## Dialogs

- Product (`products.newProduct` / `products.editProduct`): name, brand, category, GST rate (0 / 5 / 12 / 18 / 28 %), HSN (optional, 4 / 6 / 8 digits, `products.fields.hsnHelp`), formulation, active ingredient, own brand, active. Server `product_exists` marks the name field; `validation_error` field errors are shown per field.
- SKU (`products.addSku` / `products.editSku`): pack size (> 0), unit (ml, l, g, kg, pcs), barcode (optional; `barcode_exists` shown on the field), MRP in rupees (sent as integer paise), active.
- Import (`import.titleProducts`): file picker -> automatic dry run -> report (`import.summary`, table of row / column / problem) -> Apply (`import.apply`) only when the dry run has no errors.

## States

| State | Behaviour |
|---|---|
| Session loading | Skeleton (`session-loading`) |
| Signed out | ErrorState `session.signedOutTitle` / `signedOutHelp` + sign-in link (`session-signed-out`) |

| Empty | EmptyState `products.emptyTitle` / `emptyHelp` |
| Empty after filters | `products.emptyFilteredTitle` / `emptyFiltered` |
| Error | DataTable ErrorState with retry; message from the problem code (`problems.*`) |
