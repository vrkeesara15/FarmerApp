# S10 Day close

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store/day-close`. Requirements: ST-006 (+ ST-002 expected cash).

Implementation: `apps/mobile/apps/agent/lib/screens/store/day_close_screen.dart`.

## Layout

Two panes at >= 700 dp: count (left), result (right).
1. `storeCashCount` (`dayclose-count`): rows ₹500 / ₹200 / ₹100 / ₹50 / ₹20 / ₹10 notes x count (`dayclose-note-<paise>`) with the row value, `storeCoins` in rupees (`dayclose-coins`), `storeCountedCash` total (`dayclose-counted`) = `denominationTotal`.
2. Result (`dayclose-result`): `storeExpectedCash` (day summary `expected_cash_paise`), counted, `storeVariance` (`dayclose-variance`, live; success at 0, warning, danger over the threshold), `storeVarianceOver(₹500)` (`dayclose-over-threshold`) when |variance| > the default threshold (the server applies the tenant's threshold and notifies auditors); `storeDepositSlip` thumbnail + `storeTakePhoto` / `storeRetakePhoto` (`dayclose-photo`; in-app camera only, NF-004 1280 px JPEG, resumable upload `purpose=receipt` on submit); `storeSlipRequired` when cash was counted without a slip; `storeCloseNotes`; `storeCloseDay` (`dayclose-submit`) -> `POST /v1/stores/{id}/day-close`.
3. Closed state (`dayclose-closed`): `storeDayClosedTitle`, time, expected / counted / variance, `storeFlagged` chip (`dayclose-flagged`), notes. 409 `day_already_closed` shows `storeDayAlreadyClosed` (`dayclose-already`) above the closed summary; no second submit.
Cluster heads see the status and expected cash only (reopen stays in the console).
