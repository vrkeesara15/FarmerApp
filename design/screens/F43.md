# F43 Weather

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-008 with NF-002, NF-009. Derived from SPEC 13.3 ("F43 Weather 7-day detail") and SPEC 2.4 FM-008 ("Spray advice hides windows with rain or wind above threshold").

Implementation: `apps/mobile/apps/farmer/lib/screens/advisory/weather_screen.dart` (route `/weather`), `widgets/advisory_widgets.dart`.

## Purpose

The farm's weather for seven days and, under it, when it is good to spray over the next three days — with the reason whenever it is not.

## Components used

| Component | Notes |
|---|---|
| AppBar | `weatherTitle` |
| Day row | WMO pictogram, date, `weatherSky`, `weatherTempRange(min, max)`, `weatherRainChance(pct)` (`weather-day-<YYYY-MM-DD>`) |
| Spray section | `weatherSprayTitle` + `weatherSprayNextDays` (`spray-section`) |
| Good block | Green outline, check icon, `weatherSprayGood`, the window time (`spray-good-<start>`) |
| Avoid block | Amber outline, "do not disturb" icon, `weatherSprayAvoid`, and the reasons `weatherReasonRainLikely` / `weatherReasonRain` / `weatherReasonWindHigh`, plus the cautions `weatherCautionHeat` / `HumidityHigh` / `HumidityLow` (`spray-avoid-<start>`) |
| No good window | `weatherSprayNone` (`spray-none`) |
| Advice note | `weatherAdviceOnly` with an info icon and an `AudioButton` (`spray-advice-only`) |
| AsOfLabel | "Updated ..." / "Offline. Saved on ..." |

## Data fields shown

| Field | Source |
|---|---|
| 7 days | `GET /v1/farms/{id}/weather` `daily[]`, cached as `kisan.cache.weather.<farmId>` |
| Spray blocks | `spray.windows` (good) and `spray.avoided` (hidden), both 3-hour IST slots |
| Thresholds | `spray.thresholds` from the tenant settings |

## The hiding rule

The server already hides a window whose rain probability, rain or wind reaches a threshold and lists it under `avoided` with reason codes. **The app re-checks the thresholds itself** (`SprayWindow.blockingReasons`), so a window that arrives labelled `good` but breaches rain or wind is still shown as "Do not spray" with its reason. A window is only offered when the server and the device agree. Cautions (heat, humidity) never hide a window — they are printed under it.

## States covered

| State | Behaviour |
|---|---|
| Loaded | Seven days and the spray blocks |
| No good window in 3 days | `weatherSprayNone` above the blocks |
| Offline | Banner, the cached forecast, "as of" the time it was fetched |
| No farm / no forecast | `weatherNone` + `weatherNoneHelp` (the officer can map the farm) |

## Privacy

The app never calls a weather provider. The server asks Open-Meteo for the 0.1-degree grid cell the farm falls in and sends no farmer, id or polygon (NF-011).

## Accessibility and literacy

Pictograms always with words, 16 sp body text, and the "advice only" sentence is read aloud, because it is the one thing a farmer must not miss.
