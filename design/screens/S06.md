# S06 Stock list

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store/stock`. Requirements: ST-003 (UI), ST-004 highlight.

Implementation: `apps/mobile/apps/agent/lib/screens/store/stock_screen.dart (+ stock_adjust_dialog.dart)`.

## Layout

1. Search (`stock-search`), chips `storeFilterLow` (`stock-filter-low`), `storeFilterExpiring` (`stock-filter-expiring`), categories (`stock-cat-*`). App bar actions for managers: S07 (`stock-receipt`), S08 (`stock-transfer`).
2. Rows (`stock-row-<sku>`): name + pack, `OwnBrandBadge`, on hand / reserved / available (`stock-available-<sku>`), chips `storeLowStock` (`stock-low-<sku>`) and expiry (`stock-expiry-<sku>`: `storeExpired` / `storeExpiring30` in danger, `storeExpiring60` in warning); the row border takes the expiry colour. Data: `GET /v1/stores/{id}/stock` joined with the catalogue.
3. Detail (right pane / sheet; `storeSelectSku` until one is picked): batches FEFO (`batch-<id>`) with `storeBatch`, `storeExpires` / `storeNoExpiry`, quantities, tinted when expiring; manager actions `storeWriteOff` (`batch-writeoff-<id>`) and `storeAdjust` (`batch-adjust-<id>`).
4. Write-off dialog (`writeoff-dialog`): reason chips damage / expiry / other, quantity (<= available, `storeQtyTooHigh`), note, optional photo (in-app camera -> NF-004 -> upload, `storePhotoAdded`) -> `POST .../stock/write-offs`. Adjust dialog (`adjust-dialog`): counted quantity + reason (required) -> `POST .../stock/adjustments`. `negative_stock` -> `storeNegativeStock`.
