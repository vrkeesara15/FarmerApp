# A54 Payment link sent

Surface: Field agent app "Mitra", Light and Sunlight, 360x800.
Requirements: FA-021 (payment link via SMS / WhatsApp).

Implementation: `screens/payments/link_screen.dart`. Route `/payments/:id/link`.

## Layout

1. Sent icon, `linkSentTitle` (or `upiPaid` once paid), amount, `linkSentVia(channel)` (`channelSms` / `channelWhatsapp`), the short link, `linkValidUntil`.
2. `linkResend`: SMS / WhatsApp buttons (keys `link-resend-sms|whatsapp`, disabled offline) create a new link through that channel (`linkResent`).
3. Bottom: `linkCheckStatus` (one status call) and `paymentDone`.

## Behaviour

The link is created online (`POST /v1/payments` mode `payment_link`, `channel`); the webhook marks it paid.

Every state has an offline banner (`OfflineBannerLive`); strings are ARB keys in all five languages; money via `formatInr`.
