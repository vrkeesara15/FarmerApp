# A12 My day timeline (shell)

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. From A10 "My day".
Requirements: VV-007 (client side: sessions and how they ended), VV-008 (P1 — gaps and reasons; **EmptyState here until then**), VV-001 / VV-002 (pending / accepted points), FA-023 groundwork (client km estimate; the server's km from VV-006 replaces it in the console).

Implementation: `apps/mobile/apps/agent/lib/screens/home/my_day_screen.dart` (`MyDayScreen`) over `myDayProvider` (`DutyRepository.watchDay`, IST day bounds). Route `/home/day`.

## Layout (top to bottom)

1. AppBar `myDayTitle`.
2. Map (`MapPanel`, open polyline, no corner markers, non-interactive, 200 dp) when the day has ≥ 2 points.
3. Three StatTiles: km today (`myDayKm`, client haversine over the day's points), points pending (`syncPending`), points accepted (`syncSynced`, from the `location_batch` results).
4. One card per session (key `day-session-<id>`): `myDaySessionActive(start)` (green) or `myDaySession(start, end)`; subtitle `myDayKm(km) · myDayPoints(pending, accepted) · end reason` (`myDayEndReasonManual|AutoTime|AutoIdle|Forced|Rejected`).
5. Gaps: EmptyState `myDayGapsTitle` / `myDayGapsHelp` (key `my-day-gaps`) — VV-008.

## States

| State | Behaviour |
|---|---|
| Loading | Spinner |
| No session today | EmptyState `myDayEmpty` / `myDayEmptyHelp` (key `my-day-empty`) |
| Active session | Green card "Duty since 09:00", live counts |
| Ended sessions | Start – end, reason |
| Error | ErrorState with retry |
| Sunlight | Black text, 2 dp borders |

## Data

| Field | Source |
|---|---|
| Sessions | `duty_sessions` started in the IST day |
| Track / km | `location_buffer` points of those sessions (kept for two days after batching) |
| Pending | points with `batch_id` null |
| Accepted / rejected | `sync_docs` `location_batch` rows: server `{accepted, rejected[]}` merged on `applied` |

## Copy keys

`myDayTitle`, `myDayKm`, `syncPending`, `syncSynced`, `myDaySession`, `myDaySessionActive`, `myDayPoints`, `myDayEndReason*`, `myDayEmpty(Help)`, `myDayGapsTitle/Help`.
