# C22 Day replay

Surface: Web console, Light and Dark. Route `/field-team/{id}/replay?date=YYYY-MM-DD` (+ AN-011 filters; the date defaults to the filter's end day).
Requirements: WC-002 acceptance "Replay shows track, visits and gaps", AN-003. Roles: owner, director, tenant admin, auditor, cluster head (own cluster), field officer (self). **Store managers never see this page** (SPEC 2.6: "Location tracks are never shown to store managers or other officers"): no entry points (C21 picker and links hidden), the page does not call the API for them and shows `replay-forbidden` with `replay.forbiddenHelp`; a 403 from the API shows the same state.

Implementation: `apps/console/app/(console)/field-team/[id]/replay/ReplayView.tsx`; map `components/analytics/maps/ReplayMap.tsx` (Leaflet, OSM tiles, lazy, no SSR); playback maths `lib/replay.ts`; ProofChecklist `components/analytics/ProofChecklist.tsx`. Data: `useDayReplay` over `GET /v1/analytics/officers/{id}/day-replay`.

## Layout

1. Back link "Officer profile"; header "Day replay · {name}", the day; date input (`replay-date`) writes `?date=`.
2. Summary StatTiles: km travelled, visits, verified, stops, gaps.
3. Left (map column):
   - Map (`replay-map`): track polyline split at every gap (`.replay-track`), gap segments **dashed** in danger colour from the last point before to the first point after (`.replay-gap`, tooltip "Gap of 1h 30m: No reason given" or the VV-008 reason), stops (info dots, `.replay-stop`), visit pins coloured by status — verified (success), partial (warning), unverified (danger), open (muted) (`.replay-visit-<status>`, click selects the visit), playback marker (Leaf dot, faded while in a gap).
   - Legend with text labels for every mark.
   - Playback bar (`playback`): Play / Pause, slider 0–1000 over the day's span (`replay-slider`, `aria-valuetext` = HH:mm), clock (`replay-clock`), "No location recorded" badge while the time is inside a gap.
   - "Gaps in the track" list: HH:mm–HH:mm, duration, reason or **"No reason given"** (warning colour) + note that officers will give reasons (VV-008).
4. Right panel (380 px):
   - Timeline (`replay-timeline`): every event (duty start / end, check-in / check-out with farmer, stop, gap start with its reason, gap end) with HH:mm; the item at or before the slider time is highlighted (`data-active`, `aria-current="step"`) and scrolled into view; clicking an item moves the slider there and selects its visit. Export = CSV of the timeline.
   - Visit details (`visit-detail`): farmer (link → C31), VisitScoreBadge, purpose, check-in / check-out, duration, location check, photos, **ProofChecklist** (at the farm, photo, farmer confirmed, time on farm — Done / Missing text + points; integrity as a caption when it scored 0).

## States

| State | Behaviour |
|---|---|
| Store manager | `replay-forbidden` (no request) |
| 403 / 404 | `replay-forbidden` / `not-found-state` |
| Loading | map + panel skeletons |
| No duty that day | EmptyState `replay.emptyTitle` / `emptyHelp` |
