# A20 Farmer list

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes. Reached from the Farmers tab of the bottom nav (A10, M2) and from A21e after a save.
Requirements: FA-012 (P0), FA-025 (offline-first). Derived from SPEC 13.2 "A20 Farmer list with search, filters (village, crop, due balance), FarmerCards".

Implementation: `apps/mobile/apps/agent/lib/screens/farmers/farmer_list_screen.dart` (route `/farmers`, `AppRoutes.farmers`), rows from `farmerListProvider(FarmerListFilter)` over `FarmerRepository.watchFarmers` (Drift `farmers` + `farms` + `crop_plots` + `villages` + `synced_refs` crops, live via `tableUpdates`). Works fully offline.

## Purpose

Find a farmer in two taps in the field: type a name, the last digits of a phone or a village; or filter by village / crop. Every farmer captured offline shows immediately with a "Will sync when online" note.

## Layout (top to bottom)

1. AppBar, title `farmersTitle`; trailing `SyncStatusPillLive` (tap → A64).
2. `OfflineBannerLive` (only while offline).
3. Search field (`farmersSearchHint`, search icon), key `farmers-search`.
4. Horizontal filter row: `Village` and `Crop` popup menus (`farmersFilterVillage`, `farmersFilterCrop`, first entry `farmersFilterAll`); an active filter is shown as "Village: Kondapur" in primary. Due-balance filter arrives with the khata (M3).
5. Count caption `farmersCount(n)` and a list of `FarmerCard`s (name, village, up to two crop chips, last visit, `pendingSync` note, `attention` badge when the server rejected the farmer).
6. FAB `farmersAddFarmer` (person-add icon) → A21.

## Components used

| Component | Notes |
|---|---|
| FarmerCard | `pendingSync` (cloud icon + `farmerPendingSync`), `attention` (danger badge `farmerRejected`) added with FA-012 |
| CropChip | crop names from the `crop` feed in the UI language (`CropRef.nameIn`) |
| SyncStatusPill | live |
| OfflineBanner | live |
| EmptyState | `farmersEmptyTitle` / `farmersEmptyHelp` + action, or `farmersNoResults` when a search / filter matches nothing |
| ErrorState | only if the stream fails |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Name, village | `farmers.name`, `villages.name` via `village_id` (typed `village_name` fallback) | Ramesh Reddy, Kondapur |
| Crops | distinct `crop_plots.crop_id` across the farmer's farms | Cotton, Chilli |
| Pending sync | `farmers.dirty` | "Will sync when online" |
| Attention | `outbox` row for the farmer in `rejected` | badge "Needs attention" |
| Search | name / village contains; digits-only query matches the phone suffix | "3210" |

## Actions and navigation

| Action | Result |
|---|---|
| Type in search | list filters live (case-insensitive) |
| Village / Crop menu | `FarmerListFilter` updated; "All" clears |
| Tap a card | `context.push('/farmers/<id>')` → A22 |
| FAB | `context.push('/farmers/new')` → A21 |
| Sync pill | A64 |

## States covered

| State | Behaviour |
|---|---|
| Empty (no farmers) | EmptyState with "Add farmer" action |
| No match | EmptyState "No farmers match your search" |
| Offline | banner; list unchanged (local data) |
| Pending / rejected farmers | note / badge on the card |
| Sunlight | black text, 2 dp borders, no tinted containers |

## Accessibility

Cards are buttons labelled "<name>, <village>"; badges pair icon and text; search field has a hint; touch targets ≥ 48 dp.

## Copy keys

`farmersTitle`, `farmersSearchHint`, `farmersAddFarmer`, `farmersEmptyTitle`, `farmersEmptyHelp`, `farmersNoResults`, `farmersFilterVillage`, `farmersFilterCrop`, `farmersFilterAll`, `farmersCount`, `farmerPendingSync`, `farmerRejected` — all five languages.
