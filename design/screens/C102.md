# C102 Settings with live preview of both apps

Surface: Web console, Light and Dark. SideNav "Settings" for owner, director and tenant admin (`GET` / `PATCH /v1/settings` roles); others get ForbiddenState and no nav entry.
Requirements: WC-012 (acceptance "changes audited"), SEC-028.

Implementation: `apps/console/components/admin/SettingsView.tsx`, `BrandingPreview.tsx`; form model `lib/settings-form.ts` (`toForm`, `toSettings`, `toPatch`, `validateSettingsForm`, `fieldForLoc`). Data: `useSettings` / `useUpdateSettings` (step-up).

## FA-008: the preview is the derived palette

The two phone mock-ups paint `brandedPalette(colour, "light")` from `apps/console/lib/brand.ts` — the same derivation the console shell applies to its own tokens and, as a line-for-line Dart port (`packages/core/lib/src/theme/brand.dart`), the one both apps apply. A colour that would fail WCAG AA is shown here already corrected, so the preview is what the officer and the farmer will actually see rather than the raw swatch. `preview-agent-header[data-colour]` therefore carries the derived primary, not the typed hex.

## Layout

Two columns (stacked below 1280 px): the form on the left, the sticky live preview on the right.

| Group | Fields (unit shown; API unit) | Range |
|---|---|---|
| Visits and geofence | Geofence radius (m) · Default meeting-point radius (m, optional = geofence) · Minimum visit time (min, decimals; s) · Consent text version | 10-2000 m · 10-2000 m · 0-1440 min · 1-32 chars |
| Duty and location | Auto duty end (time input, IST) · End duty after idle (min) · Location interval moving / stationary, upload interval (s) · Location policy version | HH:MM · 5-720 · 30-3600 / 60-7200 / 60-86400 |
| Credit and money | TA per km (₹; paise) · Store manager credit limit (₹) · Credit due after (days) · Day-close variance alert (₹) · Payment webhook replay window (s) · Legal name · Invoice prefix · GSTIN by state (rows: 2-digit state code + GSTIN, add / remove) | ₹0-100 · ₹0-10,00,00,000 · 1-730 · ₹0-1,00,000 · 30-86400 · ≤200 · A-Z0-9 ≤8 · GSTIN pattern |
| Languages | Enabled (checkboxes in native script) · Default (must be enabled) | ≥1 |
| Branding | Field agent app name · Farmer app name (empty = Mitra / Kisan) · Primary colour (picker + #RRGGBB) · Support phone · Logo URI | ≤40 · hex · 8-15 digits · ≤512 |

Rupees accept up to 2 decimals and are sent as integer paise; minutes are sent as seconds. Errors appear under each field ("Enter a whole number from 10 to 2000 m."); server 422 `invalid_settings` errors map back to their fields.

Footer (sticky): status text (no changes / "N setting groups changed" / error), Discard, **Save settings** (sends only the changed keys; nested sampling / branding key by key) -> step-up -> "Saved and audited." with "View in the audit log" -> `/admin/audit?entity=tenant&action=tenant_settings.update`.

## Live preview

Two phone mockups (`preview-agent`, `preview-farmer`): header bar in the chosen colour with logo (https / data image, else the first letter) and app name; readable text colour picked by luminance; agent home (greeting, Start duty, Today's visits, Farmers nearby) and farmer home (greeting, Check my crop, My farms, "Help: {support phone}"). Updates on every keystroke, before saving.
