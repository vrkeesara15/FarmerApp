# A60 My performance

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. From Me. Route `/me/performance`.
Requirements: FA-024 (visits, farmers added, confirmations, sales, collections, incentive earned to date — equal to the console for the same officer and period), WC-009 (targets and incentive), VV-005 (only verified visits count).

Implementation: `apps/mobile/apps/agent/lib/screens/field/performance_screen.dart` (`PerformanceScreen`) over `performanceProvider` (`FieldRepository.watchPerformance`, the `kv` cache). `refreshPerformance` pulls `GET /v1/me/performance?from=&to=` for the current IST month and, in the same call, this month's `GET /v1/targets?subject_type=officer`.

## Layout (top to bottom)

1. AppBar `performanceTitle`; OfflineBannerLive.
2. `fieldAsOf(time)` caption.
3. `perfTargetsVsActual` card with four `TargetRow`s — `statVisitsVerified` (key `perf-verified-visits`), `perfNewFarmers`, `perfSales`, `statCollections`. Each shows `perfOfTarget(actual, target)` and a progress bar, or `perfNoTarget` when the tenant set none.
4. Incentive card (key `perf-incentive`): `perfIncentive` with the payout, or `perfIncentivePending` while the tenant has no active incentive rules (the API sends `incentive_earned_paise: null`).
5. `perfTrendTitle` with a 14-day bar `Sparkline` (key `perf-trend`, bars keyed `sparkline-bar-<i>`).
6. Two StatTiles: `perfConfirmationRate` and `perfRank(rank)`.

## States

| State | Behaviour |
|---|---|
| Loading | Spinner |
| No cache, no network | EmptyState `perfEmpty` / `perfEmptyHelp` (key `performance-empty`) |
| No targets | Actuals with `perfNoTarget` under each row |
| No incentive rules | `perfIncentivePending` |
| Offline | The cached month with its "as of" line |
| Sunlight | Black text, 2 dp borders |

## Data

| Field | Source |
|---|---|
| Visits, verified, farmers, sales, collections, km/day, rank, incentive | `GET /v1/me/performance` (cached in `kv` under `field.performance.<from>.<to>`) |
| Targets | `GET /v1/targets?month=&subject_type=officer` (first row for this officer) |
| Verified-visit trend | the device's own synced `visits` rows, bucketed by IST day over 14 days — no extra endpoint, and it renders offline |
