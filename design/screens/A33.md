# A33 Check-out summary

Surface: Field agent app "Mitra", Light and Sunlight. Reached from A31 `visitCheckOut` and from a checked-out VisitCard.
Requirements: FA-017 (auto duration; under the minimum is flagged, not rejected), VV-004 / VV-005 (score and status are server-owned).

Implementation: `apps/mobile/apps/agent/lib/screens/visits/summary_screen.dart` (route `/visits/:visitId/summary`).

## Layout

1. AppBar `visitSummaryTitle` (no back arrow; `visitDone` leaves).
2. Farmer, purpose · check-in time (IST).
3. `VisitScoreBadge` (key `summary-score`, 1.4x): the local expectation (`evaluateVisitProof` at check-out) with `visitSummaryPending` (key `summary-expected`) until the pull / conflict echo stores the server's `score`, `status`, `score_components`, `duration_s`, `flags`; then that score with `visitSummaryServer` (key `summary-server`). **Server wins.**
4. `visitSummaryDuration` fact row (server `duration_s` when known).
5. Under the minimum (`flags` contains `under_minimum`, or locally below `min_visit_duration_s`): warning box key `summary-under-minimum`, `visitUnderMinimum(min)` — a warning, never a block.
6. `visitSummaryOverridePending` when the geofence override is still waiting for the cluster head.
7. `visitSummaryMissing` (or `visitSummaryComplete`) + ProofChecklist (key `summary-proof`) built from the server components once stored; `proofIntegrityIssue` when integrity scored 0.
8. Primary `visitDone` (key `summary-done`) → A34.
