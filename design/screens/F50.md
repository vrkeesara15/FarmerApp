# F50 Khata

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-010 (P0) with FA-022, NF-002. Derived from SPEC 13.3 (F50), 13.1 components and SPEC 2.4 / 7.

Implementation: `apps/mobile/apps/farmer/lib/screens/khata_screen.dart` (route `/khata`), core `KhataLedger`, `KhataRepository`.

## Purpose

What the farmer owes: balance, overdue, due date, history, and "Pay now" by UPI. When the payment shows paid the khata is fetched again at once (the server posts the credit in the webhook transaction, so the balance moves within the 1-minute budget, FA-021) and F51 shows the receipt.

## Components used

| Component | Notes |
|---|---|
| KhataLedger | Balance header, due date, entries (Sale on credit / Payment received / Adjustment), "Pay now" |
| Overdue line | Red `khataOverdue` |
| AsOfLabel | Cache time |
| UPI sheet | As F32 |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Khata | `GET /v1/farmers/{id}/khata` (every page) cached in `khata_snapshots` | ₹12,500.00 · Due on 30-11-2026 |
| Dues payment | `POST /v1/payments {farmer_id, store_id, amount_paise, mode: upi_qr}` for the balance at the store with the largest balance | upi://pay?… |

## Actions and navigation

| Action | Result |
|---|---|
| Pay now | UPI → poll → paid → khata refresh → F51 |
| Pull down | Refresh |

## States covered

| State | Behaviour |
|---|---|
| Offline | Cached khata with "as of" |
| Not loaded | `kisanKhataNotLoaded` |
| Payment failed | `kisanPaymentFailed`, balance unchanged |
| Zero balance | Pay now hidden |

## Accessibility and literacy

Every icon is paired with a text label; targets are at least 48 dp; body text 16 sp or larger; the key instruction has an `AudioButton` next to it (NF-009: device TTS in the chosen language behind the `AudioPrompt` seam, "Audio unavailable" when the phone has no voice for it). No text input (NF-010). At most two decisions on the screen.
