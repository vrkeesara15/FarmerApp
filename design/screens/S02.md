# S02 POS

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store/pos`. Requirements: ST-001.

Implementation: `apps/mobile/apps/agent/lib/screens/store/pos_screen.dart`.

## Layout

Two panes at >= 700 dp: product pane (`pos-grid-pane`) and a 320 dp cart pane (`pos-cart-pane`, `CartPanel`); phones: product pane + `CartBar` (`pos-cart-bar`).
1. Search (`pos-search`: name / brand / pack / barcode), then `storeScan` (`pos-scan`, camera via `mobile_scanner`: EAN-13 / 8, UPC-A / E, Code 128) and `storeEnterCode` (`pos-enter-code`, dialog `pos-code-field` / `pos-code-add`) side by side. Both call `GET /v1/catalog/barcode/{code}?store_id=` and add one pack; snackbar `storeScanAdded(name)` / `storeScanNotFound(code)` / `storeScanOffline`.
2. Category chips (`pos-cat-all`, `pos-cat-<category>`).
3. Buyer bar: 10-digit phone (`pos-buyer-phone`) + `storeBuyerFind` (`pos-buyer-find`), helper `storeBuyerWalkIn`. A farmer on the device (Drift `farmers` by `+91` phone) shows the name; an unknown number shows `storeBuyerUnknown` and is sent as `farmer_phone`; `storeBuyerClear` returns to walk-in.
4. Product grid: the shared `ProductCard` (name, pack, store price pre-tax, `OwnBrandBadge`, stock at the store, Add / Added), 2 columns at >= 440 dp pane width.
5. Cart panel: lines (`cart-line-<sku>`) with name, pack, unit price, qty stepper (`cart-dec|inc-<sku>`, 0 removes), line value (`cart-total-<sku>`); `storeSubtotal`, `storeGst`, `storeRoundOff` (when not zero), `storeTotal` (`cart-grand-total`) from the local GST preview; `cartCheckout` (`pos-checkout`) -> S03. Empty: `storeCartEmpty` / `storeCartEmptyHelp`.
Cluster heads never reach it (no Sell in the rail; the screen shows `storeNotAllowedTitle`).
