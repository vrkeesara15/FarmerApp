# C10 Owner home

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. SideNav "Home" (`nav.home`); landing page after sign-in.
Requirements: WC-001 (loads in under 3 s for 50 stores), AN-001 (owner home dashboard), AN-011 (filters in the URL). Roles: owner, director, tenant admin, auditor, cluster head (own cluster), store manager (own store); others see the no-access state and no nav entry.

Implementation: `apps/console/app/(console)/home/OwnerHomeView.tsx`. Data: `useOwnerHome` (`lib/hooks/analytics.ts`) over `GET /v1/analytics/owner-home` + `useFilterOptions` (stores, officers, crops) in parallel. Filters: `useAnalyticsFilters()` (`lib/hooks/use-analytics-filters.ts`) + `AnalyticsFilterBar`.

## Layout (top to bottom)

1. Page header `home.title`, date range (DD-MM-YYYY – DD-MM-YYYY), scope note (`analytics.scope.*`), "Updating…" while a filter change loads (previous data stays on screen).
2. FilterBar (cluster, store, officer, crop, date; export = CSV of the store table).
3. KPI row (`data-testid="kpi-row"`), seven KpiCards in API order, each with the SPEC 5.2 definition in an InfoTip tooltip, target + progress (higher-is-better KPIs), last-year comparison footer, trend arrow (first vs last bucket of the period's trend; red when a lower-is-better KPI rises) and a sparkline:

| KPI | Example | Target | Last year |
|---|---|---|---|
| Revenue (`kpis.revenue`) | ₹3.42 Cr | ₹3.24 Cr | Last year ₹2.91 Cr (+17.5%) |
| Own-brand share | 39.8% | 45.0% | Last year 38.1% (+1.7 pts) |
| Credit outstanding | ₹1.18 Cr | — | Last year ₹1.02 Cr (+15.7%) |
| Credit overdue | ₹38.6 L | ₹23.6 L | … |
| Verified visits | 3,418 | 3,600 | … |
| Active farmers | 6,912 | 7,200 | … |
| Open flags | 31 | 0 | … |

4. "Revenue and own-brand share" — two line charts side by side (one axis each, no dual axis): revenue this period (Leaf) vs last year (muted, dashed); own-brand share (Turmeric). Day buckets up to 31 days, week buckets above.
5. "Own-brand share of sales" donut (the only pie-type chart in the console): own brand (Turmeric) vs multi-brand (neutral), share in the middle, legend with ₹ values.
6. "Stores by performance" map (Leaflet + OpenStreetMap tiles, lazy, no SSR): one pin per store coloured by band — On track 80+ (success), Watch 50–79 (warning), Behind < 50 (danger), No sales (muted); tooltip name / revenue / own-brand share / band; click → C41. Band legend with text labels; "Show stores as a table" (sortable DataTable, same data, the accessible alternative).
7. "Credit overdue by age" bars (0–30, 31–60, 61–90, 90+ days).
8. Top 5 / bottom 5 officers by verified visits per duty day (link → C21 with the filters).
9. Open high-severity flags (link → `/flags/{id}`, SeverityBadge, rule, opened DD-MM-YYYY HH:mm, store).
10. Crop health alerts: EmptyState `home.cropHealthEmptyTitle` until AN-006.

## Performance

One API call (≈1.2 s for 50 stores in the API's benchmark) fetched in parallel with the option lists; KPIs render as soon as it lands; Recharts and Leaflet are separate chunks loaded behind skeletons, so first meaningful content does not wait for them. Every section has its own skeleton.

## States

| State | Behaviour |
|---|---|
| Session loading | Skeleton (`session-loading`) |
| Signed out | `session-signed-out` with sign-in link |
| Role without access | `forbidden-state` (`analytics.forbiddenTitle` / `forbiddenHelp`) |
| Loading | KPI card skeletons + section skeletons |
| Refetch after filter change | previous data + `analytics.updating` |
| 422 `invalid_filter_combination` / `invalid_date_range` | `invalid-filters-state` with Reset filters |
| 404 (id out of scope) | `not-found-state` with Reset filters |
| Other errors | ErrorState with retry |
| Empty | per section: `home.noSalesTitle`, `home.noStoresTitle`, `home.noFlagsTitle`, `home.cropHealthEmptyTitle` |
