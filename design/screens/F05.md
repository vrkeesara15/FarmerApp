# F05 Welcome

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-003 (P0) with NF-010. Derived from SPEC 13.3 (F05), 13.1 components and SPEC 2.4 / 7.

Implementation: `apps/mobile/apps/farmer/lib/screens/welcome_screen.dart` (route `/welcome`), `widgets/farm_edit.dart` (`FarmSummaryCard`, `showChoiceSheet`); shown once after F04.

## Purpose

If a field officer registered the farmer: "Your farm details from Ramesh (field officer)" with each farm (map thumbnail, size, irrigation, soil) and its crops with stages, to confirm ("Yes, this is right") or change simple fields with icon tiles. Otherwise a quick setup in two steps: crop tiles + village from a list, then land size + sowing time tiles. Two decisions per step, no typing.

## Components used

| Component | Notes |
|---|---|
| Officer header | Avatar icon + `kisanWelcomeFromOfficer(name)` (first name) or `kisanWelcomeFromYourOfficer` when the API gives no name |
| FarmSummaryCard | `MapPanel` thumbnail (120 dp, non-interactive) or a field pictogram; chips irrigation / soil with icons; crop rows with stage icon |
| Choice sheet | Bottom sheet of `ChoiceTile`s (icon + label) for stage (`CropStages`), irrigation (`IrrigationTypes`), soil (`SoilTypes`) |
| AppButton | "Yes, this is right" (primary) and "Something is wrong: change" (secondary) |
| Quick setup | `ChoiceGrid` of crop tiles (`cropsProvider`), village list (synced `villages`), land tiles (1, 2, 5, 10+ acres), sowing tiles (this week / this month / 1–2 months / 3+ months) |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Profile | `GET /v1/farmers/{id}` (`FarmerDetailOut`) cached as `kisan.cache.profile` | Home farm, 2.5 acres, Borewell, Black |
| Officer | optional `officer {id, name, phone}` on the farmer detail (API follow-up), else `registered_by` | Ramesh |
| Crops | `farms[].crop_plots[]` crop id → crop names in the app language | Cotton · Flowering |

## Actions and navigation

| Action | Result |
|---|---|
| Yes, this is right / Done | Marks the welcome done (`kv kisan.welcome_done`), F10 |
| Change | Values become tappable; a tile saves at once: `PATCH /v1/crop-plots/{id}` `{version, stage}` or `PATCH /v1/farms/{id}` `{version, irrigation | soil}`, then the profile is fetched again |
| Quick setup Save | `PATCH /v1/farmers/{id}` `{village_id}` when changed, `POST /v1/farmers/{id}/farms` with one crop plot (season from the sowing date), F10 |
| Skip for now | Marks the welcome done, F10 |

## States covered

| State | Behaviour |
|---|---|
| Officer-registered | Prefilled, read-only until "change" |
| Quick setup | Next disabled until a crop is chosen; Save until size and time are chosen |
| Offline | A change says "This needs internet…" and keeps the value |
| Version conflict | "Could not save"; the profile is fetched again |
| No villages on the phone | `kisanSetupNoVillages` |

## Accessibility and literacy

Every icon is paired with a text label; targets are at least 48 dp; body text 16 sp or larger; the key instruction has an `AudioButton` next to it (NF-009: device TTS in the chosen language behind the `AudioPrompt` seam, "Audio unavailable" when the phone has no voice for it). No text input (NF-010). At most two decisions on the screen.
