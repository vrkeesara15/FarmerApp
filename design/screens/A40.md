# A40 Camera (scouting)

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FA-019 (scouting: photo diagnosis using DX), FM-004 gate reused, DX-001. Derived from SPEC 13.2 "A40 Camera with CameraGuideOverlay".

Implementation: `ScoutCameraScreen` in `apps/mobile/apps/agent/lib/screens/scouting/scouting_screens.dart` (route `/farmers/<farmerId>/scout/camera`) on the shared `GuidedCameraView`.

## Entry

A22 **Scout** (now live, `profile-scout`) or Home **Scout crop** (`home-scout` → farmer picker with `?for=scout`) → the crop plot choice (`/farmers/<id>/scout`: "Choose the crop plot", one card per plot: crop · farm, stage; "This farmer has no crop plot yet" when none). Picking a plot starts a capture session with subject `officer`, the farmer and `CropChoice(code, cropId, cropPlotId, stage)`.

## Behaviour

Same as F21: live `camera`-plugin preview, `CameraGuideOverlay` (leaf frame, three tips, the refused photo's tip lit), "Photo n of 3", 80 dp shutter; each shot → `PhotoProcessor` → DX-001 gate → A41. Camera refused / missing → message + Try again.

## Copy keys

`scoutTitle`, `scoutChoosePlot`, `scoutPlotLine`, `scoutNoPlots`, `cameraLeafFrame`, `cameraHoldSteady`, `cameraGoodLight`, `cameraFillFrame`, `cropDoctorPhotoCount`, `cropDoctorTakePhoto`.
