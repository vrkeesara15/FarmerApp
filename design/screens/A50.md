# A50 Product search and catalogue

Surface: Field agent app "Mitra", Light and Sunlight, 360x800.
Requirements: FA-020 (order capture: product search, own-brand badge, stock at nearest store), FA-025 (works offline).

Implementation: `apps/mobile/apps/agent/lib/screens/orders/catalog_screen.dart` over `catalogSearchProvider(CatalogQuery)` (`CatalogCache.watchSearch`, Drift `catalog_products` / `catalog_skus` / `catalog_prices` / `stock_snapshots` / `catalog_stores`). Route `/orders/new?farmerId=` (A22 "New order", Orders tab → farmer picker).

## Layout

1. AppBar `catalogTitle` with `catalogForFarmer(name)` subtitle; refresh action (key `catalog-refresh`, disabled offline).
2. `OfflineBannerLive`; search field (key `catalog-search`, hint `catalogSearchHint`): every word must appear in the name, brand, active ingredient or a localised name.
3. Category chips (horizontal scroll, keys `catalog-category-all|<wire>`): `catalogCategoryAll`, seeds, fertilisers, pesticides, fungicides, herbicides, growth promoters, tools, other.
4. Freshness line (key `catalog-freshness`): `catalogAsOf(time)`; warning style `catalogStale(time)` when offline or older than 24 h; `catalogRefreshFailed`, `catalogStoreUnknown` when relevant.
5. ProductCards (key `product-<skuId>`), own brand first then by name: OwnBrandBadge, pack, price with `productPriceEstimate`, stock line `productStockAtStore(n, store)` / `productStockNearest(n)` / `productOutOfStock` + `productStockAsOf(HH:mm)`, add button (`productAdd` / `productInCart(n)`); out of stock disables add.
6. CartBar (key `cart-bar`, `estimate: true`): item count, `cartEstimatedTotal`, action `cartViewCart` → A51.
7. Empty: `catalog-never` (`catalogNeverLoaded` / `catalogNeverLoadedHelp`) when nothing was ever downloaded, `catalog-empty` (`catalogEmpty` / `catalogEmptyHelp`) for no match; loading `Skeletons.list`.

## Behaviour

Opening online refreshes a stale cache: `GET /v1/stores/nearest?farmer_id=` (store remembered per farmer), `GET /v1/catalog/products?store_id=` (every page), then nearest again with the SKUs for `available` (on hand − reserved).

Every state has an offline banner (`OfflineBannerLive`); strings are ARB keys in all five languages; money via `formatInr`.
