# A22 Farmer profile

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes. Reached from an A20 card, from A21e after a save and from the duplicate links.
Requirements: FA-012, FA-013, FA-025. Derived from SPEC 13.2 "A22 Farmer profile with tabs: Overview (key facts, crops, map), Visits, Diagnoses, Orders, Khata. Primary actions: Start visit, Scout, New order, Collect."

Implementation: `apps/mobile/apps/agent/lib/screens/farmers/farmer_profile_screen.dart` (route `/farmers/:farmerId`), data from `farmerDetailProvider(id)` over `FarmerRepository.watchFarmer` (farmer, village, farms with plots and decoded boundary, consents, the rejected outbox error and the synced farmer with the same phone).

## Layout

1. AppBar: farmer name; `TabBar` Overview / Visits / Diagnoses / Orders / Khata (`profileTab*`).
2. `OfflineBannerLive`.
3. Banner (when relevant): **Duplicate — merge?** (`profileDuplicateTitle` + `profileDuplicateBody`, warning colour) with `regDuplicateOpen` → A22 of the existing farmer (merge itself is console work, WC-104); or `profileRejectedTitle` + the server detail with `profileRejectedHelp` → A64.
4. Overview tab: `farmerPendingSync` row while the farmer has queued ops; facts card (phone + verified / unverified, village, landmark, language, land, both consents); `profileVerifyPhone` (placeholder until the record OTP flow lands) when unverified; crop chips across farms; `profileFarms` with `profileAddFarm` → A23; one card per farm: name, `profileEditFarm` → A23, mini `MapPanel` (non-interactive), "x acres · n crops · soil · irrigation", crop chips with season.
5. Other tabs: `EmptyState` (`profileVisitsEmpty` … `profileKhataEmpty`, help `profileComingSoon`) — filled by FA-014+, DX, ST and khata milestones.
6. Bottom action row: four disabled secondary `AppButton`s with labels `profileStartVisit`, `profileScout`, `profileNewOrder`, `profileCollect` (tooltip `profileComingSoon`).

## Data

| Field | Source |
|---|---|
| Facts | `farmers` row (+ `villages`) |
| Farms / plots | `farms`, `crop_plots` (not tombstoned) |
| Consents | `consent_records` |
| Pending | `farmers.dirty` |
| Duplicate | rejected `outbox` op with code `farmer_phone_exists`; link = clean local farmer with the same phone |

## States

| State | Behaviour |
|---|---|
| Not found | `profileNotFound` EmptyState |
| Pending sync | info row |
| Rejected (duplicate) | warning banner + link |
| Rejected (other) | danger banner + A64 link |
| No farms | `profileNoFarms` |
| Sunlight | theme-level |
