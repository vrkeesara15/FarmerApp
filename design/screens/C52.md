# C52 Price lists

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. SideNav "Price lists" (`nav.prices`), route `/products/prices`.
Requirements: WC-005 (price lists by store). Money is integer paise; inputs are rupees with up to 2 decimals.

Implementation: `apps/console/app/(console)/products/prices/PricesView.tsx`. Data: `useStores`, `useProducts`, `usePriceLists`, `usePutPriceLists` over `GET /v1/catalog/stores`, `GET /v1/catalog/price-lists?store_id=`, `PUT /v1/catalog/price-lists`. Rule check: `validatePriceRow` in `lib/catalog-schemas.ts`.

## Layout

1. Page header `prices.title` / `prices.subtitle`, sub-navigation.
2. Filter bar: price list selector (`prices.store`): "Tenant default (all stores)" (`prices.tenantDefault`) + stores ("Warangal (WGL)"); Add price (`prices.addRow`) and Save changes (`prices.saveChanges`, count of pending rows) for owner / director / tenant admin.
3. Rule line `prices.rule`.
4. DataTable:

| Column | Example |
|---|---|
| SKU | FCC Imida · 100 ml (select for new rows) |
| MRP | ₹220 |
| Price (₹) | ₹209 or inline input "209.00" |
| Effective from | 01-05-2026 (locked for existing rows: it is the upsert key) |
| Effective to | Open ended (`prices.openEnded`) or date |
| Check | per-row error (`problems.priceAboveMrp`, `problems.priceOverlap`, `validation.*`) or `prices.unsaved` |
| Actions | Edit (`prices.edit`) / Cancel |

Saving sends every pending row in one `PUT` (all or nothing). Client check first (price ≤ MRP, dates); server `price_above_mrp` (422) and `price_overlap` (409) carry `rows[].index`, mapped back to the edited rows.

## States

| State | Behaviour |
|---|---|
| Role without price access | ErrorState `problems.forbidden` / `prices.forbiddenHelp` |
| Loading | skeleton rows |
| Empty | `prices.emptyTitle` with `prices.emptyDefault` (tenant default) or `prices.emptyStore` |
| Error | ErrorState with retry |
| Save error | inline alert above the table + per-row messages |

## Copy keys

`prices.*`, `problems.priceAboveMrp`, `problems.priceOverlap`, `validation.money`, `validation.date`, `validation.dateOrder`, `nav.prices`.
