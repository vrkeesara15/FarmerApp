# C20 Field team

Surface: Web console, Light and Dark. SideNav "Field team" (`nav.fieldTeam`).
Requirements: WC-002, AN-002 (field team scorecard), AN-011. Roles: owner, director, tenant admin, auditor, cluster head (own cluster), store manager (own store, no km), field officer (own row only).

Implementation: `apps/console/app/(console)/field-team/FieldTeamView.tsx`. Data: `useFieldTeam` over `GET /v1/analytics/field-team`.

## Layout

1. Header `fieldTeam.title`, range, scope note; for store managers `fieldTeam.noLocation` ("Distances and tracks are not shown for your role.").
2. FilterBar (cluster, store, officer, crop, date; export = CSV of the scorecard).
3. Definitions row with InfoTips (verified visit, unique farmers, confirmation rate, time on farm, conversion — SPEC 5.2).
4. DataTable, client-side sortable on every numeric column, default order = API rank:

| Column | Example |

Row click → C21 with the current filters.

## States

Session / role / 403 / 404 / 422 as C10; loading = DataTable skeleton rows; empty = `fieldTeam.emptyTitle` / `emptyHelp`; error = DataTable ErrorState with retry.
