# A34 Visits list

Surface: Field agent app "Mitra", Light and Sunlight. Bottom nav `navVisits` on A10, route `/visits`.
Requirements: FA-014 .. FA-017 (visit history with verification status), FA-025 (sync state per item, works offline).

Implementation: `apps/mobile/apps/agent/lib/screens/visits/visits_list_screen.dart` over `visitListProvider(VisitListQuery)` (`VisitRepository.watchVisitsBetween`, local `visits` table). `VisitSummaryCard` is shared with the A22 Visits tab (`farmerVisitsProvider`).

## Layout

1. AppBar `visitsTitle` + sync pill; tabs `visitsTabToday` / `visitsTabWeek` (keys `visits-tab-today|week`; IST day, and the 7 IST days ending today).
2. Status filter chips (wrap, keys `visits-filter-all|open|verified|partial|unverified`): `visitsFilterAll`, `visitStatusOpen`, `visitVerified`, `visitPartial`, `visitUnverified`.
3. VisitCards (key `visit-card-<id>`), newest first: farmer, purpose, IST time, duration (server `duration_s`, else check-out − check-in, else running), `VisitScoreBadge` once scored or the "In progress" pill (`visitStatusOpen`) while open; footnote `visitCardPending` (queued ops on the visit or its photos) or `visitCardFailed` (danger, rejected check-in). Tap: open → A31, checked out → A33.
4. Empty: `EmptyState` key `visits-empty` (`visitsEmptyTitle`, `visitsEmptyHelp`).
5. Extended FAB `actionStartVisit` (key `visits-start`) → A30.
