# S01 Store home

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store`. Requirements: ST-001, ST-002, ST-005, ST-006 (and the cheap ST-004 highlight).

Implementation: `apps/mobile/apps/agent/lib/screens/store/store_home_screen.dart`.

## Layout

1. Action row (Wrap): `storeActionNewSale` (primary, `store-action-sale`, sellers), `storeActionReceive` / `storeActionTransfer` (secondary, `store-action-receipt|transfer`, store manager), `storeActionCloseDay` (`store-action-close`, manager / accountant).
2. Two-column card grid at >= 600 dp content width (one column below):
   - `storeTodaySales` (`store-sales-card`): display-size total of all modes incl. credit (`store-sales-total`), `storeSalesCount`, one `StoreAmountRow` per mode (`storeModeUpi|Card|Cash|Credit`) from `GET /v1/stores/{id}/day-summary`.
   - `storeQueueCounts` (`store-queue-card`): four `StatTile`s New / Packing / Ready / Handed over (`store-queue-count-<tab>`); tap -> S05.
   - `storeLowStock` (`store-stock-card`): `storeLowStockCount` (available <= 10, `lowStockThreshold`; the product master has no reorder level yet) and `storeExpiringCount` (a batch with stock expires within 60 days or has expired); tap -> S06.
   - `storeDayCloseStatus` (`store-dayclose-card`): chip `storeDayOpen` / `storeDayClosed(time)` / `storeDayReopened`, expected cash, variance once closed (danger when flagged); tap -> S10.
3. Pull to refresh reloads summary, queue and stock.
