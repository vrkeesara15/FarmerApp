# S04 Invoice / receipt share

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store/invoice/:invoiceId`. Requirements: ST-001.

Implementation: `apps/mobile/apps/agent/lib/screens/store/invoice_screen.dart`.

## Layout

Two panes at >= 700 dp: header + actions (left), invoice (right).
1. Header (`invoice-header`): `storeInvoicePaid`, `storeInvoiceNo(number)` (`invoice-number`), IST time, total (display), `storeCashChange` for a cash sale (`invoice-change`), seller name + `storeGstin`, address, `storeInvoiceBuyer` + buyer name.
2. Invoice: `GstInvoiceView.invoice` from `InvoiceOut` (server numbers) with `storeAmountInWords` (`invoice-words`).
3. Actions: `storeShareWhatsApp` (`invoice-whatsapp`, primary) -> `POST /v1/invoices/{id}/share {channel: whatsapp, phone}` -> snackbar `storeShareSent(to)` / `storeShareFailed`; `storeOpenPdf` (`invoice-pdf`) -> `GET /v1/invoices/{id}/pdf` signed URL opened outside the app (`url_launcher` behind `UrlOpener`), `storePdfFailed`; `storeShareOther` (`invoice-share`) -> system share sheet (`share_plus` behind `TextSharer`) with `storeShareText(number, amount, url)`; `storeNextSale` (`invoice-next-sale`) clears the POS.
