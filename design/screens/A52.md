# A52 Payment method

Surface: Field agent app "Mitra", Light and Sunlight, 360x800.
Requirements: FA-021 (UPI QR, payment link, cash, credit).

Implementation: `screens/payments/checkout_screen.dart`. Routes `/orders/checkout` (cart order) and `/farmers/:id/collect` (khata dues, from A22 "Collect", A58 and Home "Collect payment").

## Layout

1. AppBar `checkoutTitle` + farmer.
2. Order mode: `checkoutOrderAmount` (estimate). Dues mode: `checkoutDuesBalance(amount)` and the amount field (key `checkout-amount`, defaults to the balance at the store with the largest balance; partial allowed; over the balance → `checkoutDuesTooMuch`).
3. PaymentMethodSelector (keys `payment-method-<method>`): offline UPI QR and link are disabled with `checkoutNeedsInternet`; credit disabled for dues with `checkoutCreditOrdersOnly`; credit hint `checkoutCreditLeft(limit − balance)` from the cached khata.
4. `checkoutOfflineNote` offline; error line `checkout-message`.
5. Bottom `checkoutPlaceOrder` / `checkoutCollect` (key `checkout-submit`).

## Behaviour

Place order queues the `order` op (credit: order without payment mode, then a `payment` credit op). Cash → A57 + A55; credit → A57 + A56 (sync if online); UPI / link → sync, then `POST /v1/payments` only once the order is on the server (else A57 + `checkoutOrderNotSynced`); refusals map `already_paid`, `amount_mismatch`, `nothing_due`, `requires_network`.

Every state has an offline banner (`OfflineBannerLive`); strings are ARB keys in all five languages; money via `formatInr`.
