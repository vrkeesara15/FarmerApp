# A30 Start visit

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. Reached from A10 quick action `actionStartVisit` (key `home-start-visit`), A22 primary action `profileStartVisit` (key `profile-start-visit`, farmer + first farm preselected) and the A34 FAB (`visits-start`).
Requirements: FA-014 (check-in only within the farm geofence or at the village meeting point; outside needs an override note and cluster-head approval), FA-010 (visits are on-duty work), FA-028 (device integrity on the check-in), VV-003.

Implementation: `apps/mobile/apps/agent/lib/screens/visits/start_visit_screen.dart` (route `/visits/new?farmerId=&farmId=`), logic `packages/core/lib/src/visits/visit_flow.dart` (`VisitFlow.precheck`, `checkIn`), geometry `packages/core/lib/src/geo/geo.dart` (`pointInPolygon`, `distanceToPolygonMetres`) and `visit_models.dart` (`evaluateGeofence`, mirror of the API's `farmerapp/visits/geofence.py`).

## Layout

1. AppBar `actionStartVisit` + `SyncStatusPillLive`; `OfflineBannerLive`.
2. **Off duty** (no open `duty_sessions` row): `EmptyState` key `visit-off-duty` — `visitOffDutyTitle` / `visitOffDutyBody`, action `visitGoHome` → A10. Nothing else is shown; no op can be queued.
3. **No farmer** chosen: `visitChooseFarmer` + FarmerCards (key `visit-farmer-<id>`).
4. Farmer name + village; farm chips (`visitFarmLabel`, keys `visit-farm-<id>`) when the farmer has more than one farm.
5. Purpose chips `visitPurposeLabel`: advisory, scouting, demo, collection, sale, meeting (keys `visit-purpose-<wire>`, icon + label).
6. Mini `MapPanel` (key `visit-map`, 180 dp, non-interactive): farm polygon, officer dot with accuracy ring, meeting point ring; `geofence` = `inside` (success ring, 2 dp wider) / `outside` (danger ring). `visitFarmNoBoundary` caption when the farm has no polygon.
7. Result: `visitLocating` spinner → success box key `visit-inside` (`visitInsideGeofence` / `visitAtMeetingPoint`) or danger box key `visit-outside` (`visitOutsideFarm(distance, radius)`, `visitOutsideMeeting(distance, radius)`, `visitNoTarget`); `visitAccuracy(m)`; no fix → `visitNoFix` (key `visit-no-fix`). Tertiary `visitRefreshLocation` (key `visit-refresh`).
8. Outside: secondary `visitRequestOverride` (key `visit-request-override`) reveals `AppTextField` key `visit-override-note` (`visitOverrideNoteLabel` / `visitOverrideNoteHint`, error `visitOverrideNoteRequired`) and `visitOverrideHelp`.
9. Primary `visitCheckIn` / `visitCheckInOverride` (key `visit-check-in`): disabled without a fix and while outside until "Request override" is chosen.

## Behaviour

| Step | What happens |
|---|---|
| Pre-check | One fix from the duty sampler; farm ring buffered by the tenant `geofence_radius_m` (cached in `kv` `visits.settings`, default 150 m) first, then the village meeting point within `meeting_point_radius_m` (tenant radius when null; village centre when no meeting point). Distances in metres (equirectangular edge distance, haversine for points). |
| Check in (inside) | `visit` create op `{farmer_id, farm_id, village_id, purpose, checkin_at, checkin_point{lat, lon, accuracy_m}, device_integrity{is_mock, is_rooted, clock_drift_s}, client_visit_id}`; optimistic `visits` row (`status open`, pre-check stored) → A31. |
| Check in (outside) | Without a note: error, **no op**. With a note: the same op plus `override_note`; the server decides (`override` + request to the cluster head; geofence scores 0 until approved). |
| Off duty | `CheckInResult.offDuty`, state 2. |

## States

Off duty · picking farmer · locating · inside (green ring) · meeting point · outside (distance) · outside + override note · no target · no fix · offline (everything queues) · Sunlight.
