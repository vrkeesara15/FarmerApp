# F20 Crop doctor

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-004 (guided camera, up to 3 photos), NF-002 (results cached), NF-009 / NF-010 (audio, no typing). Derived from SPEC 13.3 "F20 Crop doctor intro with 3 picture tips".

Implementation: `apps/mobile/apps/farmer/lib/screens/crop_doctor/crop_doctor_screen.dart` (route `/crop-doctor`, the Crop doctor tab and Home "Check my crop").

## Purpose

Teach the three things that make a usable photo before the camera opens, then one big button. Below it, the farmer's earlier crop checks, readable offline, with the ones the expert updated on top.

## Components used

| Component | Notes |
|---|---|
| KisanTabScaffold | Crop doctor tab selected; OfflineBanner when offline |
| Tip tiles | Three pictogram tiles: go close to one sick leaf (crop_free), sun behind you (wb_sunny), hold still and tap to focus (back_hand) |
| AudioButton | `f20_intro` reads the title, the three tips and "up to 3 photos" |
| FilledButton (96 dp) | "Open camera" (`crop-doctor-start`) → F21 |
| KisanCard list | "My crop checks": problem name (farmer's language) or out-of-scope title, ConfidenceBand, waiting / queued line, "Your result was updated" flag, time; tap → F24–F28 |

## Data fields shown

| Field | Source |
|---|---|
| Crop checks | `diagnosesProvider` (`sync_docs`, entity `diagnosis`: the queued create, then `DiagnosisOut` from the applied echo / poll / sync feed) |

## States covered

| State | Behaviour |
|---|---|
| No checks yet | Tips + button only |
| Queued offline | Row says "We’ll check when you’re online" |
| Updated by the expert (F27) | Row first, bell icon, "Your result was updated" |
| Offline | Everything from the phone; banner |
| Sunlight | Black text, 2 dp borders, no tinted containers |

## Accessibility and literacy

Tips are pictures with 2–6 words each and are read aloud; the button is 96 dp with icon + words; no text input (NF-010).

## Copy keys

`cropDoctorTitle`, `cropDoctorIntroTitle`, `cropDoctorIntroTip1..3`, `cropDoctorUpTo3`, `cropDoctorOpenCamera`, `cropDoctorMyChecks`, `cropDoctorWaiting`, `cropDoctorQueuedHelp`, `cropDoctorUpdatedTitle`.
