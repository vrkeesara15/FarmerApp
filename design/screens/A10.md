# A10 Home

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. Landing screen after onboarding; bottom nav Home.
Requirements: FA-010 (duty toggle, foreground service with persistent notification, no sampling off duty), FA-011 (toggle blocked until the policy is accepted), FA-028 (integrity banner, never blocking), VV-001 (pending points), VV-007 (auto-end time and notices), FA-025 (SyncStatusPill).

Implementation: `apps/mobile/apps/agent/lib/screens/home/home_screen.dart` (`HomeScreen`) over `dutyControllerProvider` (`packages/core/lib/src/duty/duty_controller.dart`) and `locationPolicyProvider`. Route `/home`.

## FA-008 brand header

The AppBar title is the tenant's logo (`BrandLogo`, key `home-brand-logo`; the shipped leaf when the tenant set none or the image cannot be loaded) followed by the tenant's app name (key `home-brand-name`, `branding.app_name_agent`, else the working name “Mitra”). The primary colour of every control on this screen comes from the same brand through the token system (`AppTheme.build(..., brand:)`).

## Behaviour (DutyController)

| Event | What happens |
|---|---|
| Switch on | Policy accepted? else blocked. Current fix (`LocationSampler.current`) → none: notice, stays off. `duty_session` create op `{id, device_id, app_version, policy_version, start_at, start_point, integrity}` → row → foreground service "On duty — location on / On duty for H:MM" → sampler started with the tenant policy → VV-007 prompt scheduled 10 min before auto-end. |
| Fix | `SamplingCadence` (2 min moving: speed > 0.5 m/s or > 50 m; 10 min stationary) → `location_buffer` row with accuracy, speed, bearing, battery, is_mock (`Position.isMocked` OR "allow mock locations"), is_rooted, clock_drift_s, provider; client distance updated. |
| Tick (30 s) | Elapsed + notification text; at the auto-end instant → end `auto_time` + notice + local notification; every 15 min (tenant `upload_interval_s`) → flush. |
| Wi-Fi / charging | Immediate flush (tenant `upload_on_wifi_or_charging`). |
| Flush | `location_batch` create ops of ≤ 500 points; points stamped with the batch id; server `{accepted, rejected}` kept on the batch doc for A12. |
| Switch off | Sampler and service stopped, prompt cancelled, buffer flushed, `duty_session` update `{end_at, end_point, end_reason: manual}`. |
| Server end (`conflict` with `end_at`, or pulled row) | Sampler and service stopped, notice `endedByServer`, no client end op (the server owns `end_at`). |
| `duty_already_active` / `policy_not_accepted` | Local session discarded, everything stopped, notice; the latter also forgets the acceptance so A05 returns. |
| App restart | `restore()` resumes an open session (service + sampler, cadence seeded from the last point, prompt rescheduled, buffer flushed). |

**Off duty nothing samples**: the sampler is started only after the session row exists and stopped before the end op; tests assert `starts == 0` while blocked / off.

## States

| State | Behaviour |
|---|---|
| Policy not accepted | Toggle disabled with reason + "Review policy" |
| Off duty | Toggle off, stats, quick actions |
| Starting / ending | Spinner on the toggle |
| On duty | Green card, elapsed, pending points, auto-end time |
| Notice | Info banner with close |
| Integrity issue | Warning banner, nothing blocked |
| Offline | OfflineBanner; everything queues |
| Sunlight | Black text, 2 dp borders, no tinted containers |
