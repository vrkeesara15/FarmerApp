# A07 Device registered

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. After A06.
Requirements: FA-001 (device bound to the session, SEC-020), FA-011 (onboarding complete).

Implementation: `apps/mobile/apps/agent/lib/screens/onboarding/device_registered_screen.dart` (`DeviceRegisteredScreen`). Route `/onboarding/done`.

## Layout

Centred success mark (verified icon in a success-tinted circle), `registeredTitle` (display), `registeredBody` (secondary), primary `registeredStart` ("Go to Home", key `registered-start`) → A10.

## States

Default only (the device id already exists from FA-001; there is no network call here). Sunlight: black text, 2 dp border on the circle.

## Copy keys

`registeredTitle`, `registeredBody`, `registeredStart`.
