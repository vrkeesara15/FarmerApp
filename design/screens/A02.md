# A02 Language picker

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FA-004 (P0) with NF-008, NF-009, NF-010. Derived from SPEC 13.2 (Onboarding) and 13.1 `LanguagePicker`.

Implementation: `apps/mobile/apps/agent/lib/screens/language_screen.dart` (route `/language`); the same picker is reused inside A63 through `LanguageSettingTile`.

## Purpose

First decision after A01 Splash: pick the app language once, in the user's own script, before anything else is read. Changing it here (or later in A63) re-localises the whole app immediately; no restart, and the choice survives the next app start.

## Components used

| Component | Notes |
|---|---|
| AppBar | Title `languagePickerTitle`; trailing `ThemeToggleAction` (Light/Sunlight, A63 setting exposed early for outdoor field tests) |
| LanguagePicker | 2x3 grid of 144 dp tiles: script name (title), English name in the current UI language (caption), speaker `TextButton.icon` labelled "Listen" in that tile's language, check icon on the selected tile |
| AppButton | Primary, size L, full width, icon `arrow_forward`, label `actionContinue`; disabled until a language is selected |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Selected locale | `settingsProvider.locale` (Drift `kv` key `settings.locale`) | `te`; `null` on first run |
| Tile native names | `LanguageOption.launchLanguages` (literal, never translated) | తెలుగు, ಕನ್ನಡ, हिन्दी, मराठी, English |
| Tile captions | `languageTeluguName` … in the current UI language | "Telugu" (en) / "తెలుగు" (te) |
| Listen labels | `languagePlayAudio` in each tile's own language | వినండి, ಕೇಳಿ, सुनें, ऐका, Listen |

## Actions and navigation

| Action | Result |
|---|---|
| Tap a tile | `SettingsNotifier.setLocale(locale)` → `MaterialApp.locale` updates, every visible string switches live, theme text scale switches to the Indic scale (+15% line height) for te/kn/hi/mr; value persisted to `kv` |
| Tap the speaker | `onPlayAudio(locale)` — audio prompt playback lands with the farmer audio assets (FM-001 / NF-009); the button is present now so the layout is final |
| Continue | `context.go('/login')` → A03 Phone login |
| Theme toggle | `SettingsNotifier.toggleTheme()` (persisted) |
| Back (system) | Returns to A01 |

## States covered

| State | Behaviour |
|---|---|
| Default (first run) | No tile selected, Continue disabled, strings in the device language when supported, else English |
| Selected | Tile gets primary border, tinted container (plain white in Sunlight) and check icon; Continue enabled |
| Restored | Next app start bootstraps `settingsOverrides(KvSettingsStore)` before the first frame: the saved tile is pre-selected and the screen is already in that language |
| Sunlight | Black text, 2 dp borders, no tinted containers |
| Loading / empty / error / offline | Not applicable: fully local, no network |

## Accessibility

Two explicit semantics nodes per tile: the tile ("తెలుగు, Telugu", button, selected) and the speaker ("వినండి తెలుగు", button). Touch targets ≥ 48 dp; the speaker icon always has a visible text label (NF-009). Body text 16 sp minimum.
