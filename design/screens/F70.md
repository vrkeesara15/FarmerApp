# F70 Me

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-002, FM-015 (mobile half), FA-004 with NF-009. Derived from SPEC 13.3 (F70), 13.1 components and SPEC 2.4 / 7.

Implementation: `apps/mobile/apps/farmer/lib/screens/settings_screen.dart` (route `/me`, Me tab), `consent_settings_screen.dart` (`/me/consent`), `delete_account_screen.dart` (`/me/delete`).

## Purpose

Language (with the language audio prompts), theme Light / Sunlight, notifications on / off, consent settings (current state; offers and tips can be withdrawn or given again), my crops, my field officer, help (call the store: tenant support phone), delete my account, about.

## Components used

| Component | Notes |
|---|---|
| LanguageSettingTile | Sheet with the F01 tiles and their speakers |
| SwitchListTile | Theme, notifications |
| Rows | Consent (subtitle offers on / off), My crops, My field officer, Help (support phone), Delete my account (red; subtitle with the ticket), About (version) |
| Consent settings | Data consent state card ("Given on 01-09-2026"; how to stop: delete the account) + offers `ConsentCard` with read aloud and switch |
| Delete my account | Step 1: what is deleted and kept (read aloud) + "Delete my account"; step 2: "Are you sure?" + "Yes, delete" / "No, keep my account"; then the ticket, status and due date |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Consent state | Cached profile consents + queued rows | Offers and tips: on |
| Support phone | `GET /v1/settings/public` branding | +91 … |
| Deletion ticket | `POST /v1/me/deletion-request {reason?}` → `{ticket_id, status, due_by}`; `GET /v1/me/deletion-request` | DEL-1001 · We will finish by 19-10-2026 |

## Actions and navigation

| Action | Result |
|---|---|
| Offers switch off | New consent row `granted: false` (withdrawal); on: a new grant; offline queued |
| Delete | Two steps, then the API; offline: "This needs internet…" |
| Help | `tel:` link |

## States covered

| State | Behaviour |
|---|---|
| Offline | Cached state; writes queued or refused as above |
| Ticket exists | Status screen instead of the steps |
| Endpoint missing (404) | "Could not save. Try again." |

## Accessibility and literacy

Every icon is paired with a text label; targets are at least 48 dp; body text 16 sp or larger; the key instruction has an `AudioButton` next to it (NF-009: device TTS in the chosen language behind the `AudioPrompt` seam, "Audio unavailable" when the phone has no voice for it). No text input (NF-010). At most two decisions on the screen.
