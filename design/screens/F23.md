# F23 Choose crop

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-004 (crop auto-detect with manual override), DX-001 (crop hint behind the `on_device_crop_guess` flag). Derived from SPEC 13.3 "F23 Choose crop if not detected (big crop tiles)".

Implementation: `ChooseCropScreen` in `apps/mobile/apps/farmer/lib/screens/crop_doctor/crop_camera_screen.dart` (route `/crop-doctor/crop`).

## Purpose

Which crop is in the photo, with one tap. The farmer's own crops come first (picking one attaches the check to that plot), then the six pilot crops, then "I don't know".

## Flow

- F22 Continue opens F23 when no crop is known. With the tenant flag `on_device_crop_guess` on (default **off** until the model passes field validation, ml/ondevice/INTEGRATION.md §7), the on-device guess is pre-selected and F22 shows "Crop: Chilli · Change crop" instead; F23 then says "Looks like Chilli. Tap another crop if this is wrong." The user's pick always wins; a later guess never overwrites it.
- "Check my crop" queues the diagnosis (photos + uploads + `diagnosis` create op) and opens F24.

## Components used

| Component | Notes |
|---|---|
| SpokenText | Title with audio (`f23_choose_crop`) |
| ChoiceGrid / ChoiceTile | 96 dp tiles, crop pictogram + name in the app language; keys `crop-tile-<code>`, `crop-tile-unknown` |
| AppButton | "Check my crop" (`crop-choose-submit`) |

## Data sent

`crop_id` = the plot's crop id when it is a server id, else `unknown` (pilot placeholder or "I don't know"; the server then uses the plot's crop, the guess ≥ 0.6, or the whole corpus); `crop_plot_id` for the farmer's plot; `crop_guess` only while the flag is on.

## Copy keys

`cropDoctorChooseCropTitle`, `cropDoctorDetected`, `cropDoctorUnknownCrop`, `cropDoctorCheckCrop`, `cropDoctorCropIs`, `cropDoctorChangeCrop`.

## Tests

`crop_doctor_test.dart` (tiles, plot attached, flag off: no guess; flag on: pre-selected, override wins), core `crop_doctor_capture_test.dart`.
