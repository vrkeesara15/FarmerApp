# A55 Cash receipt capture

Surface: Field agent app "Mitra", Light and Sunlight, 360x800.
Requirements: FA-021 (cash with receipt photo; requires store reconciliation), NF-004.

Implementation: `screens/payments/cash_screen.dart`, `receiptCaptureProvider` + `PaymentRepository.collectCash`. Route `/payments/cash?orderId=` or `?farmerId=&storeId=&amount=`.

## Layout

1. Farmer; `cashAmount` (order estimate / dues amount); `cashPhotoHelp`.
2. `cashTakePhoto` (in-app camera only) → NF-004 pipeline + quality gate; preview (key `cash-preview`), `cashPhotoBad` blocks saving; `cashRetake`.
3. `cashSave` → the receipt upload (purpose `receipt`) and a `payment` create op `{order_id | farmer_id+store_id+amount_paise, mode: cash, receipt_uri: upload:<id>}` (no id, no order amount: the server computes it); works offline.
4. `cashPendingReconciliation` note; after save `cashSaved` and back to A57 / A58.

## Behaviour

Status is "pending store reconciliation" until the store day close (ST-006).

Every state has an offline banner (`OfflineBannerLive`); strings are ARB keys in all five languages; money via `formatInr`.
