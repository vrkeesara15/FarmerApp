# A21 Add farmer wizard (A21a–e)

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes. Reached from the A20 FAB.
Requirements: FA-012 (P0) farmer registration, FA-013 (P0) multiple farms / crop plots, FA-025 offline, VA-F01 (phone OTP, duplicate), VA-F03 (polygon sanity, area ±30 %), NF-004 (photo pipeline), NF-009 / NF-010 (read-aloud consent, icons + text). Derived from SPEC 13.2 "A21 Add farmer wizard (Stepper, 5 steps)".

Implementation: `apps/mobile/apps/agent/lib/screens/farmers/add_farmer_wizard_screen.dart` (route `/farmers/new`) with the steps under `steps/`; state in `registrationProvider` (`RegistrationNotifier`, `packages/core/lib/src/farmers/registration_notifier.dart`); the draft (`RegistrationDraft`) is written to the Drift `kv` table (`registration.draft`) after every change and restored by `start()` so an interrupted wizard resumes at the same step.

## Shell

AppBar title `regTitle`, back (step back, or A20 on the first step), action `regDiscardDraft`; `OfflineBannerLive`; `AppStepper` with the five titles (`regStepBasics` … `regStepReview`); scrolling step body; bottom bar with `actionBack` (secondary, from step 2) and `actionNext` (primary) — `regSave` on the last step. A failed Next shows the field errors and a snackbar `regFixIssues`. Resuming a draft shows `regResumeDraft`.

## A21a Farmer details (`steps/basics_step.dart`)

| Field | Component | Notes |
|---|---|---|
| Name | AppTextField `regNameLabel` / `regNameHint` | required |
| Phone | AppTextField `indiaPhone` `regPhoneLabel`, helper `regPhoneHelper` | 10 digits 6–9; **local duplicate check** against synced farmers on every change → error `regDuplicatePhone` + tertiary `regDuplicateOpen` (→ A22 of that farmer); Next blocked |

| Language | `LanguagePicker.compact` (script-name chips) `regLanguageLabel` | required; also drives the consent notice language |
| Land | ChoiceChips `regOwnershipLabel` own / leased | optional |

## A21b Farm boundary (`steps/boundary_step.dart`)

- Segmented control `regBoundaryWalk` / `regBoundaryTap`; hint `regWalkHint` / `regTapHint`.
- `MapPanel` (OSM tiles, no key): live polygon (open line while walking), numbered corners, the officer's position with an accuracy ring.
- Walk mode: `regStartWalk` subscribes to GPS (FA-010: only on this explicit action; nothing reads location otherwise), fixes closer than 3 m to the last point are dropped, accuracy row `regAccuracy(±m)` (green ≤ 10 m, amber ≤ 25 m, red beyond) or `regAccuracyWaiting`; `regStopWalk`; `regClosePolygon` (≥ 3 points) stops GPS; `regLocationOff` / `regLocationDenied` notices.
- Tap mode: tapping the map appends a corner; `regUndoPoint`, `regClearBoundary`.
- Caption `regPointsCount(n)` and `regComputedArea(acres)` (spherical shoelace, pure Dart `polygonAreaAcres`).
- Self-intersection (`isSelfIntersecting`) → NoticeBox `regBoundaryInvalid`, Next blocked (VA-F03).
- `regAreaLabel` (declared acres, required) with `regUseMeasured`; when declared and measured differ by more than 30 % → warning NoticeBox `regAreaWarning` (VA-F03; a warning, not a block — the server records `area_mismatch` too).
- `regFarmNameLabel`, ChoiceChips `regSoilLabel` (7 soils), `regIrrigationLabel` (7 types), `regOwnershipLabel` (defaults to the farmer's).
- `regFarmPhoto`: `regTakePhoto` opens the **camera only** (`ImagePickerCameraSource`, no gallery path exists) → NF-004 `PhotoProcessor` (1280 px, q80, EXIF time + GPS) → quality gate → `PhotoReviewCard` (Retake / Use) → saved to the photo store and queued as a resumable upload; the farm op carries `upload:<id>` and waits for the blob URI.

## A21c Crops (`steps/crops_step.dart`)

Farm tabs when there are several farms (`regFarmIndex(n)` or the farm name); help `regCropsHelp`; one card per plot (`regPlotTitle(n)`): crop chips from the `crop` feed (pilot list until synced), `regVarietyLabel`, sowing date button `regSowingDateLabel` (Material date picker, shown `DD-MM-YYYY`, caption `regSeasonAuto`: Kharif Jun–Sep, Rabi Oct–Feb, Zaid Mar–May), optional `regPlotAreaLabel`, `regRemoveCrop`; `regAddCrop`; `regFarmsCount(n)` + `regAddFarm` (FA-013: new farm → back to A21b for it). Next requires every plot to have a crop and a sowing date.

## A21d Consent (`steps/consent_step.dart`)

`regConsentIntro`; two separate `ConsentCard`s in the **farmer's chosen language** (`lookupCoreLocalizations`): data consent (`consentDataCardTitle`, `consentDataCardBody`, notice `regConsentNotice`, badge `consentRequired`) and marketing consent (`consentOffersCardTitle`, `consentOffersCardBody`, notice `regConsentMarketingNotice`, `consentOptional`). Each has `consentReadAloud` (audio playback lands with NF-009; the button is in place) and a `regConsentGiven` switch. Next requires data consent (`regIssueConsent`).

## A21e Review and save (`steps/review_step.dart`)

Sections `regReviewFarmer` (Edit → A21a), `regReviewFarms` (one card per farm: mini MapPanel, declared and measured acres, soil, irrigation, photo count, crop chips with date · season, Edit → A21b of that farm; `regAddFarm`), `regReviewConsent`; info box `farmerPendingSync` + `regReviewSyncNote`; primary `regSave`.

Save = one local transaction through the `Outbox`: `farmer` create, then per farm the `farm` create and its `crop_plot` creates, then two `consent_record` creates (`data` granted, `marketing` as chosen) — client uuids, `phone_verification_token` + expiry when verified (the engine drops an expired token before sending; the farmer then syncs unverified instead of being rejected), photos as upload dependants. The draft is cleared and the app opens A22 with `regSaved`.

## States covered

| State | Behaviour |
|---|---|
| Offline | banner; OTP replaced by "verify later"; everything saved locally, synced later |
| Duplicate phone (local) | error + link, Next blocked |
| Duplicate phone (server, after sync) | op `rejected` with `farmer_phone_exists` → A64 lists it; A22 shows "Duplicate — merge?" with a link to the existing farmer |
| GPS off / denied | notices; tap mode still works |
| Self-intersecting boundary | blocked |
| Area mismatch > 30 % | warning |
| Interrupted | resumes at the same step with all data |
| Sunlight | theme-level |

## Accessibility

Every icon pairs with text; map exposes "Farm boundary, n points, Measured area x acres" and one node per corner; chips are buttons with selected state; 48 dp targets; body 16 sp.
