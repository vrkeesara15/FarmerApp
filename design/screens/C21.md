# C21 Officer profile

Surface: Web console, Light and Dark. Reached from C20 rows, C10 officer lists and visit links. Route `/field-team/{id}` (+ AN-011 filters).
Requirements: WC-002, AN-002. Roles as C20 (a field officer can open only their own profile — others 404).

Implementation: `apps/console/app/(console)/field-team/[id]/OfficerView.tsx`. Data: `useOfficer` over `GET /v1/analytics/officers/{id}`.

## Layout

1. Back link "Field team"; header = officer name, store, On duty / Off duty badge, range.
2. Replay picker (`data-testid="replay-picker"`): date input "Day to replay" (defaults to the latest duty day) + "Open day replay" → C22 `?date=`. **Hidden for store managers** and whenever `location_visible` is false (SPEC 2.6).
3. FilterBar without the officer filter; export = CSV of the duty days.
4. Scorecard StatTiles: rank, verified visits / day, verified visits, unique farmers, confirmation rate, avg time on farm, conversion, collections, km / day (only when location is visible), flags.
5. "Verified visits per week" line chart; "Visits per duty day" bars (visits muted vs verified Leaf).
6. Duty days DataTable: day (DD-MM-YYYY), start / end (HH:mm IST, "On duty" when open), km, visits, verified, time on farm, Replay link (hidden like the picker).
7. Recent visits DataTable (20): when, farmer (link → C31), purpose (`purpose.*`), VisitScoreBadge (or "Open").

## States

Loading skeletons (StatTile / DataTable); 404 → `not-found-state`; 403 → `forbidden-state`; empty duty days `fieldTeam.noDutyTitle`, empty visits `fieldTeam.noVisitsTitle`.

## Copy keys

`fieldTeam.*`, `purpose.*`, `visitStatus.*`.

## Tests

`e2e/analytics.spec.ts` (profile summary, recent visits, date picker → replay; store manager sees no picker and no replay links).
