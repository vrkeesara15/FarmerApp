# C51 Label claims editor

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. SideNav "Label claims" (`nav.labelClaims`), route `/products/label-claims`.
Requirements: WC-005 (label claims crop × pest × dose; recommendation cannot use a SKU without a matching claim), SPEC 3.4 compliance guardrails, SPEC 14.6 human gate (only the agronomist approves; the API records `approved_by` / `approved_at`), DX-007 groundwork (preview uses the guardrail function).

Implementation: `apps/console/app/(console)/products/label-claims/LabelClaimsView.tsx` + `ClaimDialogs.tsx`. Data: `useLabelClaims`, `useCreateClaim`, `useUpdateClaim`, `useApproveClaim`, `useRetireClaim`, `useClaimHistory`, `useRecommendable`, `useCrops`, `usePests`, `useProducts` over `/v1/catalog/label-claims[/{id}[/approve|/retire|/history]]`, `/v1/catalog/recommendable`, `/v1/catalog/crops`, `/v1/catalog/pests`. Validation: `makeClaimSchema` in `lib/catalog-schemas.ts`.

## Layout

Two columns at ≥ 1280 px (stacked below):

1. Left: filter bar (crop, pest or disease scoped to the crop, SKU, status all / draft / approved / retired for maintainers) + New claim (`claims.newClaim`; owner, tenant admin, agronomist); DataTable:

| Column | Example |
|---|---|
| SKU | FCC Imida · 100 ml |
| Crop | Paddy (local name when available) |
| Pest or disease | Brown planthopper |
| Dose / acre | 40-50 ml |
| Dose / 15 L tank | 4 ml |
| PHI | 40 days |
| Status | chip Draft (warning) / Approved (success) / Retired (neutral) |
| Actions | Edit (not retired), Approve (agronomist, draft only), Retire (agronomist, owner, tenant admin), Version history |

2. Right: "Preview recommendation" panel (`data-testid="recommendation-preview"`, `claims.preview.*`): crop + pest selects; list of recommendable SKUs (product · pack, OwnBrandBadge, dose per acre and per 15 L tank, PHI, MRP, PPE). Own brand first, then efficacy tier. Empty: `claims.preview.pick` / `claims.preview.none`.

## Dialogs

- Editor (`claims.newTitle` / `claims.editTitle`): SKU, crop, pest (locked when editing), dose per acre (label text), dose value (> 0) + unit (ml, g, l, kg), dose per 15 L tank, PHI (whole days ≥ 0), efficacy tier 1-3, PPE, safety text, source reference (required; CIB&RC number). Client rules mirror the API: pest must be of the crop or polyphagous; pest / disease claims only on pesticide, fungicide, herbicide or growth products. Editing an approved claim shows `claims.editApprovedHelp` and saves a new draft version (`supersedes_id`).
- Approve (`claims.approveTitle`): `claims.approveRegulatory` ("Approval is a regulatory decision. It is recorded under your name ({name}) …"), claim summary, confirm `claims.approveConfirm`.
- Retire (`claims.retireTitle`, destructive): `claims.retireHelp`.
- Version history drawer (right sheet, `claims.historyTitle`): versions newest first with status chip, dose, PHI, created / approved / retired timestamps (IST).

## States

| State | Behaviour |
|---|---|
| Session loading / signed out | as C50 |
| Loading | DataTable skeleton; preview skeleton lines |
| Empty | `claims.emptyTitle` / `emptyHelp`; filtered: `claims.emptyFilteredTitle` / `emptyFiltered` |
| Error | ErrorState with retry (problem code -> `problems.*`) |
| Server rule errors | `pest_not_for_crop`, `claim_category_invalid`, `claim_duplicate` on the field; `claim_not_draft`, `claim_retired`, `version_conflict` in the dialog |
