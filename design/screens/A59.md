# A59 Collections list

Surface: Field agent app "Mitra", Light and Sunlight, 360x800.
Requirements: FA-021 (cash requires store reconciliation).

Implementation: `screens/payments/collections_screen.dart` over `collectionsProvider(CollectionsRange)` (`PaymentRepository.watchCollections`). Route `/collections` (Orders tab action).

## Layout

1. Segmented Today / This week (IST).
2. Totals card: per mode (cash, UPI QR, link, credit) and `collectionsTotal` (money collected: credit excluded).
3. Rows (key `collection-<id>`): farmer · mode, state pill (`collectionStateWaitingToSync`, `…PendingReconciliation`, `…Waiting`, `…Paid`, `…OnKhata`, `…ApprovalNeeded`, `…Failed`), IST time, amount; order rows open A57.
4. Empty `collections-empty`.

## Behaviour

Only payments the officer collected (server `collected_by`, or captured on this device). Totals count waiting-to-sync cash, pending reconciliation, paid and on-khata; failed, waiting UPI and approval-needed do not count. A10 "Collections" stat = today's `collectedPaise`.

Every state has an offline banner (`OfflineBannerLive`); strings are ARB keys in all five languages; money via `formatInr`.
