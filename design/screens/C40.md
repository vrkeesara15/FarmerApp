# C40 Stores

Surface: Web console, Light and Dark. SideNav "Stores" (`nav.stores`).
Requirements: WC-004, AN-005, AN-011. Roles: owner, director, tenant admin, auditor, accountant, cluster head (own cluster), store manager (own store).

Implementation: `apps/console/app/(console)/stores/StoresView.tsx`. Data: `useStoresAnalytics` over `GET /v1/analytics/stores`.

## Layout

1. Header `stores.title`, range, scope note.
2. FilterBar (export = CSV of the table, money in rupees).
3. Definitions (own-brand share, credit overdue).
4. "Net sales and gross margin by store" — horizontal bars sorted by net sales (net sales Leaf, gross margin muted); shown when more than one store is in view.
5. DataTable (sortable), row → C41:

| Column | Example |
|---|---|
| Store (+ code · district) | FCC Warangal · WGL · Warangal |
| Net sales | ₹14.8 L |
| Gross margin / Margin % | ₹2.9 L / 19.6% |
| Own-brand share | 41.2% |
| Orders | 812 |
| Stock value | ₹21.4 L |
| Credit outstanding / overdue | ₹6.1 L / ₹1.9 L |
| Last day-close variance (+ date) | ₹-420 · 18-09-2026 (danger when above ₹500) |
