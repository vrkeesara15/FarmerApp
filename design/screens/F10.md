# F10 Home

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-010, FM-011, FM-003 with NF-002, NF-009; weather FM-008 and alerts FM-009 are P1 placeholders. Derived from SPEC 13.3 (F10), 13.1 components and SPEC 2.4 / 7.

Implementation: `apps/mobile/apps/farmer/lib/screens/home_screen.dart` (route `/home`), `widgets/kisan_widgets.dart` (`KisanTabScaffold`).

## FA-008 brand header

`KisanTabScaffold(showBrandLogo: true)`: the tenant's logo (key `home-brand-logo`) and the tenant's app name (key `home-brand-name`, `branding.app_name_farmer`, else “Kisan”) in the app bar, and the tenant's primary colour through the tokens. Cached, so a cold start opens already branded.

## Purpose

The farmer's start: greeting, a pending "Did Ramesh visit…?" card, weather strip (empty state until FM-008), a very large "Check my crop" button (→ F20 crop doctor), a "Your result was updated" card when the expert confirmed or corrected a crop check (F27, key `home-diagnosis-updated`), dues card when the khata balance is above zero, pest alert banner (placeholder until FM-009), my crops with stage and next task (placeholder until FM-007), shortcuts, bottom navigation.

## Components used

| Component | Notes |
|---|---|
| KisanTabScaffold | AppBar "Kisan", `OfflineBanner`, NavigationBar Home / Crop doctor / Orders / Me (icons with labels) |
| Visit card | `KisanCard` with `kisanVisitQuestion(name)` → F60 |

| Dues card | `kisanDuesTitle(amount)`, due date, "Pay now" → F50; only when balance > 0 |

| Shortcuts | ActionChips: My field officer (F62), Khata (F50), Scan visit QR (F60) |

## Data fields shown

| Field | Source | Example |

## States covered

| State | Behaviour |
|---|---|
| Loaded | All cards |
| Offline | Banner; everything from the cache with "as of" |
| No crops | `kisanNoCropsYet` card |
| No dues | Dues card hidden |
| No prompt | Visit card hidden |

## Accessibility and literacy

Every icon is paired with a text label; targets are at least 48 dp; body text 16 sp or larger; the key instruction has an `AudioButton` next to it (NF-009: device TTS in the chosen language behind the `AudioPrompt` seam, "Audio unavailable" when the phone has no voice for it). No text input (NF-010). At most two decisions on the screen.
