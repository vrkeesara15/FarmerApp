# A08 Signed out by your administrator

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight; the farmer app "Kisan" shows the same screen (route `/signed-out`). Shown after a remote wipe.
Requirements: SEC-025 (remote wipe when a user is disabled or the device is reported lost), SEC-024 (the encrypted database and its key are deleted).

Implementation: shared widget `apps/mobile/packages/core/lib/src/widgets/signed_out_screen.dart` (`SignedOutScreen`), routed at `/signed-out` in `apps/agent/lib/router.dart` (`AppRoutes.signedOut`) and `apps/farmer/lib/router.dart`. The router opens it first while the `kv` record `security.wipe_notice` exists (`wipeNoticeProvider`, read at start-up).

## When it shows

1. The server answers 401 `device_wipe_required` to any call (sync, a screen's read, token refresh, login), or `GET /v1/devices/me/status` on start answers `wipe_required: true`.
2. The app replaces the UI with a spinner (`WipeInProgressView`, no text: the providers are already torn down), stops the duty foreground service and the location sampler, forgets the session, deletes the encrypted database and its Keystore-held key, photos, pending uploads and caches, cancels background sync (officer app), and starts again.
3. The fresh database holds only the language and the notice, so this screen opens, in the language the user had chosen.

It stays across app restarts until the user taps "Sign in again".

## Layout

Scrollable column, screen padding 16 dp:

- 96 dp circle, warning-container tint, 1 dp warning border (2 dp in Sunlight), icon `phonelink_lock_outlined` 48 dp in warning colour. Decorative (excluded from semantics).
- `wipeTitle` (display), centred, announced as a header.
- `wipeBody` (body, primary text): what happened, in one sentence, no blame.
- `wipeDeletedList` (body, secondary): what was deleted, including work that was not yet sent, and that the language is kept.
- `wipeWhatNext` (body, secondary): contact the administrator; sign in again once they allow it.
- Primary `AppButton` pinned at the bottom: `wipeSignInAgain` (icon `login`, key `wipe-sign-in`) → removes the notice and goes to the language step (A02 / F01), then the normal phone + OTP login.

Warning tone, not error red: the user did nothing wrong; the administrator acted (disabled account or phone reported lost). No error codes, no support jargon.

## States

Single state. Sunlight: black text, 2 dp border on the circle. Long translations scroll; the button never leaves the screen.

## Related copy

`loginDeviceNotBound` on A04 / F03 (SEC-020): an officer signing in on a phone other than the one bound to them gets "This phone is not registered to you. Ask your administrator to approve it, then sign in again." The phone number is kept; no wipe happens.

## Copy keys

`wipeTitle`, `wipeBody`, `wipeDeletedList`, `wipeWhatNext`, `wipeSignInAgain`, `loginDeviceNotBound` (all five languages).
