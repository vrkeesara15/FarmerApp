# F42 Crop calendar

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes, five languages.
Requirements: FM-007 with NF-002, NF-009, NF-010. Derived from SPEC 13.3 ("F42 Crop calendar: timeline of tasks with reminders on/off") and SPEC 2.4 FM-007.

Implementation: `apps/mobile/apps/farmer/lib/screens/advisory/crop_calendar_screen.dart` (route `/crops/<cropPlotId>/calendar`).

## Purpose

One crop plot's tasks as a timeline by week: what to do, when, in the farmer's own language, read aloud on demand; mark a task done; turn its reminder on or off. When the sowing date moves, a "what changed" note explains it and says the finished work stays finished.

## Components used

| Component | Notes |
|---|---|
| AppBar | The crop's name in the farmer's language, `calendarTitle` as the fallback |
| "What changed" card | `calendarChangedTitle` + `calendarChangedLater/Earlier(days, count)` or `calendarChangedTasks(count)`, `calendarChangedDoneKept`, an `AudioButton` and `calendarGotIt` (`calendar-changed`) |
| SpokenText | `calendarHelp` with audio |
| Week heading | `calendarWeek(n)` counted from the sowing date (`calendar-week-<n>`) |
| Task card | Task-type pictogram, title, `taskTypeLabel`, the due day or window, the one-line instruction, `AudioButton` (`audio-task_<taskKey>`), "Late" chip when overdue (`task-late-<id>`) |
| FilterChip | `calendarMarkDone` / `calendarDone` (`task-done-<id>`) |
| FilterChip | `calendarRemindMe` / `calendarReminderOff` (`task-reminder-<id>`) |
| Queued mark | Cloud icon while a change waits in the outbox (`task-queued-<id>`) |
| AsOfLabel | "Updated ..." / "Offline. Saved on ..." |

## Data fields shown

| Field | Source |
|---|---|
| Tasks, titles, instructions | Cached `GET /v1/me/calendar` (`kisan.cache.calendar`), texts per language from the agronomist's templates |
| Sowing date, today | Same body (`today` is the server's IST date) |
| What changed | Computed on the device by comparing the tasks before and after a refresh (`kisan.cache.calendar_changes`) |

## Actions and navigation

| Action | Result |
|---|---|
| Speaker | Reads the title and the instruction in the chosen language (NF-009) |
| Mark done | `PATCH /v1/calendar/tasks/{id}` `{status}`; offline a `crop_plot_task` update is queued |
| Remind me | Same endpoint with `{reminder_enabled}`; the 07:00 IST job only messages tasks that are on |
| Got it | Clears the "what changed" note on this phone |

## States covered

| State | Behaviour |
|---|---|
| Loaded | Tasks grouped by week, earliest first |
| Sowing date moved | "Your calendar changed" card with the number of days and tasks |
| Overdue | "Late" chip |
| Offline | Banner, the cached calendar, changes queued with `calendarSavedOffline` |
| No calendar | `calendarNoTasks` + `calendarNoTasksHelp` |

## Accessibility and literacy

16 sp body text, 48 dp targets (the chips use `MaterialTapTargetSize.padded`), icons always paired with words, every task readable aloud, no text input. The golden set covers Light, Sunlight and Telugu.
