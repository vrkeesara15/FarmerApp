# C80 Campaigns list

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. Route `/campaigns` (SideNav "Campaigns"). Owners, directors and tenant admins write; auditors read.
Requirements: WC-008 (campaigns), AN-008 (campaign ROI).

Implementation: `apps/console/components/growth/CampaignsView.tsx` (route `app/(console)/campaigns/page.tsx`) over `lib/hooks/growth.ts` -> `GET /v1/campaigns?status=` (cursor pages, newest first).

## Layout

1. Header "Campaigns" — "SMS, WhatsApp and app messages to farmers who granted marketing consent." — with **New campaign** (write roles only) linking to C81.
2. Status filter (`?status=` in the URL): All, Draft, Scheduled, Sending, Sent, Cancelled, Failed.
3. DataTable: **Campaign** (bold), Channel (SMS / WhatsApp / App notification), Status chip (Draft neutral, Scheduled and Sending warning, Sent success, Cancelled neutral, Failed danger), **Audience** (the frozen consented count; "—" for a draft), Send at (IST), Created.
4. Row click: a draft opens C81 (`/campaigns/new?id=…`), anything else opens C82 (`/campaigns/{id}`).

## States

Loading: DataTable skeleton rows. Error: `QueryError` with retry (403 -> no-access state). Empty: "No campaigns yet" / "Build a segment, write the message and schedule it." with the **New campaign** action.

## Copy keys

`campaigns.title|subtitle|new|emptyTitle|emptyHelp|filterStatus`, `campaigns.column.*`, `campaigns.status.*`, `campaigns.channel.*`, `nav.campaigns`.

## Tests

`e2e/growth.spec.ts` "C81 -> C82" opens the list, creates from it and finds the sent campaign by name.
