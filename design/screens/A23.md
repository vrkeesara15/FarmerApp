# A23 Edit farm / add second farm

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight themes. Reached from A22 ("Add farm", "Edit farm").
Requirements: FA-013 (P0) multiple farms per farmer, FA-012, VA-F03. Derived from SPEC 13.2 "A23 Edit farm / add second farm".

Implementation: `apps/mobile/apps/agent/lib/screens/farmers/farm_edit_screen.dart` (routes `/farmers/:farmerId/farms/new` and `/farmers/:farmerId/farms/:farmId`), the same `registrationProvider` in `DraftMode.farm` with a two-step `AppStepper` reusing `BoundaryStep` (A21b) and `CropsStep` (A21c, without "add another farm").

## Behaviour

- Add: a fresh `FarmDraft` for the farmer; Save → `Outbox.enqueueCreate('farm')` + `enqueueCreate('crop_plot')` per plot, in one transaction; back to A22 where the new farm card appears (pending sync).
- Edit: the farm row and its plots are loaded into the draft (`existing: true`, server version kept); Save → `enqueueUpdate('farm')` with the current `base_version`, `enqueueUpdate` for kept plots, `enqueueCreate` for new ones, `enqueueDelete` for removed ones.
- Titles `farmAddTitle` / `farmEditTitle`; bottom bar `actionBack`, `actionNext`, `regSaveFarm`.
- Validation and warnings identical to A21b / A21c (≥ 3 points, no self-intersection, declared acres, VA-F03 ±30 % warning, every plot with crop + date).
