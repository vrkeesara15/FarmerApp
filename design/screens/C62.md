# C62 Diagnosis quality (basic)

Surface: Web console (1440x900, responsive check 1024x768), Light and Dark. Route `/agronomist/quality` (sub-nav "Diagnosis quality"). Agronomists and owners.
Requirements: AN-007 subset (the full dashboard is M7). DX-006 (review SLA).

Implementation: `apps/console/components/agronomist/QualityView.tsx`; figures from `lib/diagnosis-quality.ts` `summariseQuality` over `GET /v1/diagnoses?limit=200` (newest first, up to 5 pages, cut at 30 days — the list has no date filter) and `GET /v1/diagnoses/review-queue?limit=200`. The API has no summary endpoint; AN-007 (M7) replaces the data source with server figures.

## Layout

1. Header ("Basic view from the review queue and the last 30 days of diagnoses."), sub-nav, owner read-only note, info note "Interim view computed in the browser. The full dashboard (AN-007, M7) replaces it…", sample size.
2. Four KpiCards: Answered by corpus (corpus / answered), Escalation rate (sent to the agronomist queue / processed), Reviewed within 24 h (of reviewed in the period), Queue now (total, "2 past 18 h").
3. Three panels: Answered by source (corpus / LLM / agronomist / no answer bars), Queue age (< 6 h, 6–18 h, 18–24 h warning, > 24 h danger), Top unknowns (crop · out-of-scope reason or "LLM could not choose", count, top 5).
4. Test-set accuracy placeholder: "Arrives with the nightly evaluation (DX-011) in AN-007."
