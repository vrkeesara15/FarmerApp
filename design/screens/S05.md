# S05 Order queue

Surface: Field agent app "Mitra", store mode (role-gated: `store_manager`, `accountant`; `cluster_head` read-only plus S09), tablet portrait 800 x 1280 dp, Light and Sunlight. Frame: `StoreShell` (`apps/mobile/apps/agent/lib/screens/store/store_shell.dart`): at >= 700 dp a `NavigationRail` (key `store-rail`; Home / Sell / Orders / Stock / Credit / Day close, filtered by role) and two-pane content; below 700 dp a drawer (`store-drawer`) and the single-pane fallback. App bar: title, store switcher (`store-switcher`, when the user sees more than one store), settings (`store-settings` -> A63). `OfflineBanner` while offline; `storeReadOnlyBanner` (key `store-read-only`) for cluster heads. Loading = `Skeletons.list`; offline = `ErrorState` `store-offline` (`storeOfflineTitle` / `storeOfflineHelp`, retry); error = `ErrorState` `store-error`. Money via `formatInr` (integer paise). State in `packages/core/lib/src/store/` (`store_providers.dart`, `store_api.dart`, `store_models.dart`, `store_calc.dart`).

Route `/store/queue`. Requirements: ST-005.

Implementation: `apps/mobile/apps/agent/lib/screens/store/order_queue_screen.dart`.

## Layout

1. Tabs (`queue-tab-<tab>`) with counts (`storeTabWithCount`): New (placed, reserved), Packing (packed), Ready (ready), Handed over (handed over, delivered).
2. Order cards (`queue-order-<id>`): `storeOrderRef` (last 6 of the id), status chip, farmer name from the device (else `storeFarmerUnknown`, or `storeBuyerWalkIn`), items, channel (`storeChannelOfficer|FarmerApp|Pos`), `storeFulfilmentPickup|Delivery`, placed time (IST), total. Empty per tab: `storeQueueEmpty` / `storeQueueEmptyHelp`.
3. Detail (right pane at >= 700 dp, bottom sheet on phones; `storeSelectOrder` until one is picked): lines, total, notes, the tab's actions (`queue-action-<status>`): New -> `storeActionReserve` + `storeActionPack`, Packing -> `storeActionReady`, Ready -> `storeActionHandOver` + `storeActionDeliver`, plus `storeActionCancel` (destructive; reason dialog `queue-cancel-reason`, confirm disabled until a reason is typed). A button is enabled only when the server's `TRANSITIONS` allow it (`canTransition`); a 409 shows `storeTransitionFailed` and reloads. Cluster heads see no actions.
4. Pull to refresh, and `Timer.periodic(30 s)` reloads while the screen is mounted (`queueRefreshInterval`).
