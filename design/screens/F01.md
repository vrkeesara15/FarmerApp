# F01 Language picker with audio

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FA-004 (P0) with NF-008, NF-009, NF-010; audio prompts belong to FM-001 / NF-009. Derived from SPEC 13.3 (F01) and 13.1 `LanguagePicker`.

Implementation: `apps/mobile/apps/farmer/lib/screens/language_screen.dart` (route `/`, the app's first screen); reused inside F70 Me through `LanguageSettingTile`.

## Purpose

The very first thing a farmer sees. Designed for low literacy: a large title, a speaker hint, five big tiles each written in its own script with its own "Listen" button, and one primary action. Maximum one decision on the screen. Choosing a language re-localises the app immediately and is remembered.

## Components used

| Component | Notes |
|---|---|
| AppBar | Title `appNameFarmer` ("Kisan"); trailing `ThemeToggleAction` (F70 theme setting exposed early) |
| Display text | `languagePickerTitle` in `text.display` (28/36, +15% for Indic scripts) |
| Audio hint row | `AudioButton` (`f01_choose_language`): speaker + `languagePickerSubtitle`; plays the title and hint in the current language (M6, NF-009) |
| LanguagePicker | Same component as A02: 144 dp tiles, script name, English-name caption, speaker button "Listen" in the tile's language, check on the selected tile |
| AppButton | Primary, size L, full width, icon `arrow_forward`, label `actionContinue`; disabled until a language is selected |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Selected locale | `settingsProvider.locale` (Drift `kv` key `settings.locale`) | `hi`; `null` on first run |
| Tile native names | `LanguageOption.launchLanguages` | తెలుగు, ಕನ್ನಡ, हिन्दी, मराठी, English |
| Tile captions | `language<Name>Name` in the current UI language | "Hindi" (en) / "हिन्दी" (hi) |
| Listen labels | `languagePlayAudio` in each tile's own language | వినండి, ಕೇಳಿ, सुनें, ऐका, Listen |

## Actions and navigation

| Action | Result |
|---|---|
| Tap a tile | `SettingsNotifier.setLocale(locale)`: all strings switch live, Devanagari/Telugu/Kannada font fallback and +15% line height apply, value persisted |
| Tap the speaker | M6: `AudioPrompt.play(promptId: f01_language, text: kisanLanguagePrompt in that language, locale)`; the farmer app uses the device's text-to-speech voice for the locale (`TtsAudioPrompt`) until recorded clips by native speakers replace it behind the same interface (human gate). A language without a voice on the phone shows "Audio unavailable" in that language on its tile (disabled) |
| Continue | `context.go('/login')` → F02 Phone login (the only typing besides OTP, NF-010). The whole first run F01 → F05 is measured in `login_flow_test.dart` (5 screens, 8 actions, ≤ 2 decisions per screen); the < 60 s on a low-end phone check is a manual human gate (FM-001) |
| Theme toggle | `SettingsNotifier.toggleTheme()` (persisted) |

## States covered

| State | Behaviour |
|---|---|
| Default (first run) | Nothing selected, Continue disabled, UI in the device language when supported, else English |
| Selected | Tile highlighted with check; Continue enabled; title, hint and button already in the chosen language |
| Restored | Next start opens directly in the saved language with the tile pre-selected |
| Sunlight | Pure white, black text, 2 dp borders, no tints |
| Loading / empty / error / offline | Not applicable: fully local |

## Accessibility

Tile node "हिन्दी, Hindi" (button, selected) and speaker node "सुनें हिन्दी" (button); 48 dp targets; every icon has a visible text label; body ≥ 16 sp; title in display size for legibility outdoors.
