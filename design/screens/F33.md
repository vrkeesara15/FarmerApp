# F33 Order tracking

Surface: Farmer app "Kisan" (Android, 360x800 dp), Light and Sunlight themes.
Requirements: FM-010 (P0) with NF-002. Derived from SPEC 13.3 (F33), 13.1 components and SPEC 2.4 / 7.

Implementation: `apps/mobile/apps/farmer/lib/screens/orders/order_tracking_screen.dart` (route `/orders/<id>`).

## Purpose

Where the order is: placed → packed → ready → collected, with the time of each step, the items and total, and how it is paid; "Pay by UPI" while unpaid.

## Components used

| Component | Notes |
|---|---|
| StageTimeline | Placed, Packed, Ready, Collected |
| KisanCard | Items (name · pack × qty, line total), total |
| Payment row | Paid / On your khata / Pay at the store when you collect |
| AsOfLabel | Cache time |
| AppButton | "Pay by UPI" while unpaid |

## Data fields shown

| Field | Source | Example |
|---|---|---|
| Order | `GET /v1/orders/{id}` (`OrderDetailOut`, events = ST-005 history) cached as `kisan.cache.order.<id>`; line names kept from the cart / catalogue | Packed · 18-09-2026 14:00 |

## Actions and navigation

| Action | Result |
|---|---|
| Open / pull down | Refresh |
| Pay by UPI | Same flow as F32 |

## States covered

| State | Behaviour |
|---|---|
| Offline | Cached with "as of" |
| Not on the phone | `kisanOrderNotSaved` |
| Cancelled | Red "Cancelled" |

## Accessibility and literacy

Every icon is paired with a text label; targets are at least 48 dp; body text 16 sp or larger; the key instruction has an `AudioButton` next to it (NF-009: device TTS in the chosen language behind the `AudioPrompt` seam, "Audio unavailable" when the phone has no voice for it). No text input (NF-010). At most two decisions on the screen.
