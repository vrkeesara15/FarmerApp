# A11 Beat plan

Surface: Field agent app "Mitra" (Android, 360x800 dp), Light and Sunlight. From A10 "Next up" and from Me → Today's beat. Route `/beat`.
Requirements: FA-018 (daily plan with reasons, officer-editable), FA-014 (start a visit from an item), FA-025 (works offline), FA-005 (no free text here; notes on items reuse the voice field).

Implementation: `apps/mobile/apps/agent/lib/screens/field/beat_plan_screen.dart` (`BeatPlanScreen`) over `beatPlanProvider(date)` (`FieldRepository.watchBeat`, the `beat_plan` sync entity). `FieldRepository.refreshBeat` pulls `GET /v1/me/beat?date=` on open; every edit writes the whole ordered list through the outbox (`PUT /v1/me/beat` semantics).

## Layout (top to bottom)

1. AppBar `beatTitle` with a map/list toggle (key `beat-map-toggle`, `beatShowMap` / `beatShowList`).
2. OfflineBannerLive.
3. Progress line `beatTarget(done, target)` (key `beat-target`), plus `fieldPendingSync` when the plan has unsynced edits.
4. `beatReorderHint` with a drag-handle icon.
5. ReorderableListView of cards (key `beat-item-<farmerId|villageId>`):
   * leading: a drag handle (`ReorderableDragStartListener`, key `beat-drag-<id>`) — a person icon for a farmer, a village icon for a village;
   * title: farmer name, or village name for a `village` item;
   * subtitle: village name (or `beatVillageKind`) and the reason chips (key `beat-reason-<code>`): `beatReasonFollowUp` (primary), `beatReasonPestAlert` (danger), `beatReasonCreditDue` (warning), `beatReasonDemoStage` (info);
   * trailing: "start visit" (key `beat-start-visit-<farmerId>`, goes to A30 for that farmer) and remove (key `beat-remove-<id>`).
6. Footer: `farmersAddFarmer` (key `beat-add-farmer`) and `beatAddVillage` (key `beat-add-village`), each opening a bottom-sheet picker (`beat-pick-farmer-<id>`, `beat-pick-village-<id>`).

Map mode replaces the list with a `MapPanel` (key `beat-map`, the mobile Leaflet-free panel) drawing the plan's villages as an open polyline.

## States

| State | Behaviour |
|---|---|
| Loading | Spinner |
| No plan (404 or not pulled yet) | EmptyState `beatEmpty` / `beatEmptyHelp` (key `beat-empty`) |
| Plan, generated | Cards in server priority order |
| Plan, edited | Same, plus `fieldPendingSync` |
| Offline | The cached plan renders; edits queue |
| Map with no village centres | EmptyState `beat-map-empty` |
| Error | ErrorState with retry |
| Sunlight | Black text, 2 dp borders |

## Data

| Field | Source |
|---|---|
| Plan, items, reasons, target | `sync_docs` `beat_plan` (pull: `GET /v1/me/beat?date=`) |
| Farmer / village names | The plan row; officer-added items take the name from the local farmer or village row |
| Village centres (map) | `villages` table |
| Edits | outbox `beat_plan` update, payload `{items: BeatItemIn[], version}` |
