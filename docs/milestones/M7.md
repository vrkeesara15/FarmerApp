## Real defects found while building
- Diagnosis requests could never have reached the worker: the infrastructure pushed to a path the worker does not serve, and the API published to differently spelled topics.
- Deployed services would have started without their database URL, storage or encryption settings; a mis-mounted secret would have stopped the API entirely.
- Road snapping for travel allowance would have sent officers' GPS tracks outside India. Off everywhere, now requiring a data protection impact assessment.
- The console's border colours resolved to nothing in built pages after the accessibility token split.
- The officer day timeline showed an on-device distance estimate as though it were the server's processed figure, while travel allowance pays on the server number.
- Six WCAG contrast failures in the design tokens, an unlabelled map control, an unnamed consent switch, and undersized calendar cells.
