## Decisions needed
- **Sync batch latency.** A 50-operation sync batch takes about 1.1 s p95, above the flat 600 ms write budget in NF-005. Proposal: a separate objective for batched sync (for example 1.5 s p95 for up to 50 operations), because one request carries many writes.
- **Region-loss recovery point.** Losing all of asia-south1 can lose up to 24 hours of server-only writes, which misses the 15-minute RPO in NF-006. Closing it needs a cross-region read replica in asia-south2, which adds cost.
