## What changed

- **API** `apps/api/farmerapp/auth/`: `POST /v1/auth/otp/send` (202; `user_not_found`, `user_disabled`, `otp_locked` 423, `otp_rate_limited` 429), `POST /v1/auth/otp/verify` → access + refresh + profile (`otp_invalid` with `attempts_left`, `otp_expired`, `otp_not_found`, `otp_locked`), `POST /v1/auth/refresh` (rotation; `refresh_reused` revokes the whole family; `refresh_device_mismatch`), `POST /v1/auth/logout` (204, idempotent), `GET /v1/me` (401 problem+json + `WWW-Authenticate: Bearer`, `token_expired`). `get_current_user` binds `app.tenant_id` on the request session; login-by-phone runs under `app.bypass_rls = 'on'` (FA-003 makes RLS honour it). Provider adapters `FakeProvider` (tests) and `MockServerProvider` (compose mockserver, now with `GET /sms/status/{id}`); WhatsApp fallback when SMS is not confirmed delivered within 30 s via an in-process delayed-task scheduler with an injectable clock (Pub/Sub `notify.send` seam left as `PubSubScheduler`, TODO OPS-004). Structured logs carry the masked phone and challenge id, never the code. Settings gain `OTP_*`, `JWT_*`, `CORS_ORIGINS`; startup refuses `OTP_DEV_CODE`, default key/pepper or the fake provider in `prd`. `python -m farmerapp.jobs seed` upserts tenant "Future Crop Care" (`fcc`) and six test users (`+919000000001..05`, `+919000000010`).
- **Console** (C01): `lib/api.ts` calls the real `/v1/auth/*`; access token in memory, refresh token in an httpOnly SameSite=Strict cookie via `app/api/session` (store / revoke) and `app/api/session/refresh` (rotate). LoginForm shows attempts left, expiry, lockout (form disabled) and rate-limit messages from message keys (en + te). In-app mock mirrors the new shapes (lockout, resend window) so the Playwright smoke stays meaningful.
- **Mobile** (A03/A04, F02/F03): `HttpAuthApi` (package `http`) against `API_BASE_URL` (default `http://10.0.2.2:8000`), `SecureTokenStore` (flutter_secure_storage) with a persistent `device_id`, `AuthFailure` states (wrong code with attempts left, expired, locked, rate limited, not registered, offline) in both apps; `FakeAuthApi` now models lockout for tests. New ARB strings in en + te.

Design decisions: resend budget is 1 initial send + 3 resends per 15 min per phone (SPEC FA-001 wording); lockout after 5 wrong codes lasts 15 min and also blocks new sends; refresh tokens slide (each rotation gets a fresh 30 days) — forced logout arrives with WC-011.
